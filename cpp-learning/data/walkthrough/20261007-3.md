## 1. P1085 不高兴的津津

![P1085 不高兴的津津示意图](assets/walkthrough/P1085.webp)

题目来源：[洛谷 P1085](https://www.luogu.com.cn/problem/P1085)。完整题目要求以原页面为准。

### 读懂任务

把一天的两段上课时间相加，超过 8 小时才会不高兴。找总时间最长的那一天；并列时选更早的一天；整周都不超过 8 小时就输出 0。

### 像打擂台一样留下最好记录

`best` 保存当前最长时间，`answer` 保存对应星期几。把 best 初始设成 8，相当于规定“必须超过 8 才能上榜”。

按周一到周日检查，只有新时间**严格大于** best 才换记录。遇到相同时间，不换记录，就能保留更早的一天。

| 星期几 | 总时间 | 处理结果 |
| --- | --- | --- |
| 1 | 8 | 不超过 8，不更新 |
| 2 | 9 | 更新为星期二 |
| 3 | 9 | 相同，不更新 |
| 4 | 10 | 更新为星期四 |
| 5 | 10 | 相同，保留星期四 |

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int best = 8; // 只有超过 8 小时才不高兴，所以从 8 开始比较。
    int answer = 0; // 暂时没有不高兴的日子，答案为 0。
    for (int day = 1; day <= 7; day++) { // 按周一到周日的顺序检查。
        int school, extra; // 保存学校上课时间和额外上课时间。
        cin >> school >> extra; // 读入这一天的两段时间。
        int total = school + extra; // 算出这一天上课的总小时数。
        if (total > best) { // 只有比之前的记录更长，才更新答案。
            best = total; // 保存新的最长上课时间。
            answer = day; // 保存对应的星期几。
        } // 当前这一天的判断结束。
    } // 七天检查完毕。
    cout << answer << '\n'; // 输出最不高兴的星期几，或者 0。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
5 3
6 3
5 4
6 4
7 3
3 2
2 1
```

输出：

```text
4
```

再把七天都设成 `4 4`，答案应为 `0`。

**容易错：**不能用 `>=` 更新记录，否则相同时间会选中更晚的一天；恰好 8 小时不算不高兴。

只检查七天，时间和额外存储都是固定的。

小练习：七天总时间为 9、9、8、7、8、6、5，答案是多少？

## 2. P2911 Bovine Bones G（骰子点数和）

![P2911 Bovine Bones G（骰子点数和）示意图](assets/walkthrough/P2911.webp)

题目来源：[洛谷 P2911](https://www.luogu.com.cn/problem/P2911)。完整题目要求以原页面为准。

### 读懂任务

三个骰子分别有 s1、s2、s3 个面。第一个骰子的点数是 1 到 s1，其他两个类似。求哪一个点数和最常见，并列时选较小的和。

### 把每种可能都试一次

不用随机投骰子，也不用计算小数概率。三个骰子公平，每种点数组合的机会一样，所以数一数每个和有多少种组合即可。

三层循环像选衣服：第一层选第一件，第二层选第二件，第三层选第三件。每个组合都会恰好检查一次。

`count[sum]` 是点数和 sum 的计数格。遇到一个组合，就在对应格子加 1。

例如三个骰子都是两面：

| 点数和 | 对应组合 | 次数 |
| --- | --- | --- |
| 3 | (1,1,1) | 1 |
| 4 | (1,1,2)、(1,2,1)、(2,1,1) | 3 |
| 5 | (1,2,2)、(2,1,2)、(2,2,1) | 3 |
| 6 | (2,2,2) | 1 |

4 和 5 并列，答案是 4。从小到大比较，只在次数严格增加时更新，就能保留较小的和。

三个面数最大是 20、20、40，所以最大点数和为 80。数组要能使用下标 80，因此开 81 个格子，下标是 0 到 80。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int s1, s2, s3; // 保存三个骰子的面数。
    cin >> s1 >> s2 >> s3; // 读入三个面数。
    int count[81] = {0}; // 下标 0 到 80 记录每个点数和的出现次数。
    for (int a = 1; a <= s1; a++) { // 枚举第一个骰子的点数。
        for (int b = 1; b <= s2; b++) { // 枚举第二个骰子的点数。
            for (int c = 1; c <= s3; c++) { // 枚举第三个骰子的点数。
                int sum = a + b + c; // 求这一组点数的和。
                count[sum]++; // 这个和的出现次数加 1。
            } // 第三个骰子的枚举结束。
        } // 第二个骰子的枚举结束。
    } // 所有点数组合枚举完毕。
    int answer = 3; // 最小的点数和是 1+1+1，也就是 3。
    for (int sum = 4; sum <= s1 + s2 + s3; sum++) { // 从小到大检查其余点数和。
        if (count[sum] > count[answer]) { // 只有出现次数更多，才更新答案。
            answer = sum; // 保存新的最常见点数和。
        } // 当前点数和的比较结束。
    } // 所有点数和比较完毕。
    cout << answer << '\n'; // 输出次数最多、并且尽可能小的点数和。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
2 2 2
```

输出：

```text
4
```

三个普通六面骰子 `6 6 6` 的答案是 `10`，因为 10 和 11 的次数并列，选较小的 10。

**容易错：**骰子点数从 1 开始，不是从 0 开始；输出的是点数和，不是这个和出现的次数；比较时不能用 `>=`。

最多枚举 20 × 20 × 40 = 16000 个组合，再检查最多 78 个可能的和，足够快。额外只用一个固定大小的计数数组。

小练习：输入 `2 2 3`，最常见的点数和是多少？

## 3. P2141 珠心算测验

![P2141 珠心算测验示意图](assets/walkthrough/P2141.webp)

题目来源：[洛谷 P2141](https://www.luogu.com.cn/problem/P2141)。完整题目要求以原页面为准。

### 读懂任务

给出的整数全是正数，而且互不相同。统计其中有多少个数，能由另外两个不同的数相加得到。

例如列表为 `1 2 3 4 5`：3 可以由 1+2 得到，4 可以由 1+3 得到，5 可以由 1+4 或 2+3 得到。答案是 3，不能因为 5 有两种组合就把它算两次。

### 先选目标，再找一对加数

外层循环选目标 a[k]，里面两层循环选 a[i] 和 a[j]。

- 用 `j = i + 1` 保证两个人选的是不同位置，也避免把一对数正反各检查一次。
- 用 `i != k` 和 `j != k` 明确要求加数不是目标本身。
- 用 found 记住“这个目标是否已经找到组合”，一个目标最终最多让答案加 1。

`bool` 保存是或否：true 表示找到，false 表示没找到。`!found` 表示还没找到。找到后，break 结束最里面的循环；外一层循环在条件中看到 found 已经成立，也会停止。

这份代码故意直接枚举，不需要排序、查找表或复杂算法，方便跟着每一层循环理解。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int n; // 保存给出的整数个数。
    cin >> n; // 读入整数个数。
    int a[100]; // 保存最多 100 个整数，下标从 0 开始。
    for (int i = 0; i < n; i++) { // 依次读入每个整数。
        cin >> a[i]; // 把当前整数放进数组。
    } // 输入结束。
    int answer = 0; // 记录能表示成另外两个不同数之和的数的个数。
    for (int k = 0; k < n; k++) { // 轮流把每个数当作要检查的目标。
        bool found = false; // 暂时还没有找到能组成当前目标的一对数。
        for (int i = 0; i < n && !found; i++) { // 枚举第一个加数，找到后就停止。
            for (int j = i + 1; j < n; j++) { // 第二个加数在 i 后面，避免用同一个数。
                if (i != k && j != k && a[i] + a[j] == a[k]) { // 两个加数都不是目标，而且相加等于目标。
                    found = true; // 记住当前目标能够组成。
                    break; // 结束最里面的循环，不必继续找另一种组合。
                } // 当前这一对加数的判断结束。
            } // 第二个加数的枚举结束。
        } // 第一个加数的枚举结束。
        if (found) { // 如果当前目标至少有一种符合要求的组合。
            answer++; // 这个目标只计数一次。
        } // 当前目标的计数结束。
    } // 所有目标检查完毕。
    cout << answer << '\n'; // 输出符合要求的数的个数。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
5
1 2 3 4 5
```

输出：

```text
3
```

再检查 `3` 个数 `1 2 4`，答案应为 `0`。不能拿同一个 2 用两次，凑出 4。

**容易错：**题目数的是能组成的“目标数”，不是符合条件的“加数对”；输入无需有序，代码也能处理乱序的数。

n 最大只有 100。最多检查 100 × (100 × 99 / 2) = 495000 对加数，不到五十万次，直接枚举足够快。只需保存输入数组。

小练习：列表 `1 2 3 5 8` 的答案是多少？

## 4. P1068 分数线划定

![P1068 分数线划定示意图](assets/walkthrough/P1068.webp)

题目来源：[洛谷 P1068](https://www.luogu.com.cn/problem/P1068)。完整题目要求以原页面为准。

### 读懂任务

先按分数从高到低排队，分数相同的按报名号从小到大排。计划录取 m 人，用第 floor(m×1.5) 名的分数作面试分数线。所有达到分数线的人都进面试，包括与分数线同分的人。

“向下取整”就是舍去小数部分。例如 m=3 时，3×1.5=4.5，要取第 4 名的分数。注意：m 是计划录取人数，并不是最终面试人数。

### 三步完成

1. 把每人的报名号和分数放在同一张“信息卡”里，再排队。
2. 找到规定名次的分数，确定分数线。
3. 从队首数出所有达线的人，再按队伍顺序输出。

这里用 `struct Student` 定义信息卡，卡上有 id 和 score 两个格子。`students[i].score` 就是第 i 张卡片的分数。这样排序时号码和分数一起移动，不会把人的信息弄乱。

`sort` 是 C++ 现成的排序工具，我们只需要写好 better 规则：分数不同，高分在前；分数相同，小号在前。better 返回 true，表示 a 应排在 b 前面。不要把 `>` 写成 `>=`，排序规则要求相同元素不能互相声称自己应在前面。

`sort(students, students + n, better)` 的含义是按 better 规则整理前 n 张卡片。起点包含在内，终点 students+n 不包含在内。现在可以先把这一行当作一个会按规则排队的工具来使用。

用 `m * 3 / 2` 计算规定名次，整数除法自然舍去小数，不需要小数变量。名次从 1 数，数组下标从 0 数，所以第 rank 名要访问 `students[rank - 1]`。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
#include <algorithm> // 使用 C++ 提供的 sort 排序工具。
using namespace std; // 可以直接写 cin、cout 和 sort。
struct Student { // 定义一张选手信息卡，把报名号和分数放在一起。
    int id; // 这张卡片上的报名号。
    int score; // 这张卡片上的笔试分数。
}; // 信息卡的定义结束，注意这里有分号。
bool better(Student a, Student b) { // 告诉排序工具：a 是否应该排在 b 前面。
    if (a.score != b.score) { // 如果两人的分数不同。
        return a.score > b.score; // 分数高的人排在前面。
    } // 分数不同的处理结束。
    return a.id < b.id; // 分数相同时，报名号小的人排在前面。
} // 排序规则函数结束。
int main() { // 程序从这里开始。
    int n, m; // 保存报名人数和计划录取人数。
    cin >> n >> m; // 读入两个人数。
    Student students[5000]; // 准备最多 5000 张选手信息卡。
    for (int i = 0; i < n; i++) { // 逐个读入选手的信息。
        cin >> students[i].id >> students[i].score; // 把报名号和分数写到同一张卡片上。
    } // 所有选手信息读入完毕。
    sort(students, students + n, better); // 按 better 规则，把前 n 张卡片排好队。
    int rank = m * 3 / 2; // 计算 m 的 150%，整数除法自动向下取整。
    int line = students[rank - 1].score; // 第 rank 名对应下标 rank-1，它的分数就是分数线。
    int total = 0; // 暂时还没有统计进入面试的人数。
    while (total < n && students[total].score >= line) { // 从队首开始，统计所有达到分数线的人。
        total++; // 当前选手达到分数线，人数加 1。
    } // 面试人数统计完毕。
    cout << line << ' ' << total << '\n'; // 先输出分数线和实际面试人数。
    for (int i = 0; i < total; i++) { // 按排好的顺序输出进入面试的选手。
        cout << students[i].id << ' ' << students[i].score << '\n'; // 输出这名选手的报名号和分数。
    } // 进入面试的选手输出完毕。
    return 0; // 程序正常结束。
} // main 函数结束。
```

输入：

```text

```

排好的队伍：

| 名次 | 下标 | 报名号 | 分数 |

| 2 | 1 | 1002 | 90 |
| 3 | 2 | 1003 | 85 |
| 4 | 3 | 1004 | 85 |
| 5 | 4 | 1005 | 85 |

**容易错：**不能只输出前 rank 人；不能只按分数排序而忽略同分时的报名号；第 rank 名的下标不是 rank。统计时先检查 total<n，再读取数组，避免读到数组范围外。

n 最大为 5000。sort 的工作量大约随 n×log₂n 增长，随后最多扫描两遍选手数组，能满足题目范围。保存 n 张信息卡，需要随 n 增长的空间。

小练习：计划录取 5 人时，应该用第几名的分数划线？若第 7、8 名同分，第 8 名是否能进入面试？

## 练习答案

- P1085：输出 1，并列时保留星期一。
- P2911：输出 5。
- P2141：输出 3，目标分别是 3、5、8。
- P1068：用第 7 名的分数划线；第 8 名与第 7 名同分，所以也进面试。

推荐学习顺序就是本文件的顺序：先练保持最好记录，再练枚举和数组计数，接着练避免重复计数，最后学习信息卡和排序。
