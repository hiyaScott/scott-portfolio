# 1015结构体排序

这份讲义面向小学六年级学生，练习数组、结构体、排序和简单动态规划。每道题的代码可以独立提交，代码中的 `//` 后面是给人看的中文注释。

`struct` 像一张信息卡，可以把一个人的姓名、成绩、编号放在一起；`sort` 像给一摞卡片排队。排序规则要先比较最重要的条件，前一条件相同时再比较下一条。

## 1. P1271 选举学生会

![P1271 选举学生会示意图](assets/walkthrough/P1271.webp)

题目来源：[洛谷 P1271](https://www.luogu.com.cn/problem/P1271)。详细要求以原题为准。

### 解题思路

把所有选票放进数组并从小到大排序。题目要输出每张票的编号，不是统计票数。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // 排序工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n,m; cin>>n>>m; // 读入候选人数和选票数。
    int a[2000000]; // 保存选票。
    for(int i=0;i<m;i++) cin>>a[i]; // 读入每张选票。
    sort(a,a+m); // 从小到大排序。
    for(int i=0;i<m;i++) cout<<a[i]<<' '; // 输出排好后的选票。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
2 8
2 1 2 1 2 2 1 1
```

输出：

```text
1 1 1 1 2 2 2 2
```

**容易错：**m 最多两百万，sort 可以直接处理。

## 2. P5740 最厉害的学生

![P5740 最厉害的学生示意图](assets/walkthrough/P5740.webp)

题目来源：[洛谷 P5740](https://www.luogu.com.cn/problem/P5740)。详细要求以原题为准。

### 解题思路

像打擂台一样保存最高总分。总分严格更高才更新，同分自动保留输入靠前的人。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <string> // 字符串工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n; cin>>n; // 读入人数。
    string bn,name; int bc=0,bm=0,be=0,best=-1; // 保存当前最高分学生。
    for(int i=0;i<n;i++){ // 逐个检查学生。
        int c,m,e; cin>>name>>c>>m>>e; // 读入姓名和三科成绩。
        int total=c+m+e; // 计算总分。
        if(total>best){best=total;bn=name;bc=c;bm=m;be=e;} // 严格更高才更新，同分保留前面的人。
    } // 检查结束。
    cout<<bn<<' '<<bc<<' '<<bm<<' '<<be<<'\n'; // 输出答案。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
3
li 90 80 70
wang 100 80 60
chen 100 80 60
```

输出：

```text
li 90 80 70
```

**容易错：**不要用 >=，否则会错误地选择后来的同分学生。

## 3. P1223 排队接水

![P1223 排队接水示意图](assets/walkthrough/P1223.webp)

题目来源：[洛谷 P1223](https://www.luogu.com.cn/problem/P1223)。详细要求以原题为准。

### 解题思路

接水时间短的人先来，后面的人等待时间总和最小；时间相同按编号小的在前。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // 排序工具。
#include <iomanip> // 小数格式工具。
using namespace std; // 使用标准名字。
struct Person{int time,number;}; // 信息卡：接水时间和编号。
bool earlier(Person a,Person b){ // 排序规则。
    if(a.time!=b.time) return a.time<b.time; // 时间短的先接水。
    return a.number<b.number; // 时间相同，编号小的先。
} // 规则结束。
int main(){ // 程序开始。
    int n; cin>>n; Person p[1000]; // 读入人数并准备信息卡。
    for(int i=0;i<n;i++){cin>>p[i].time;p[i].number=i+1;} // 读时间和编号。
    sort(p,p+n,earlier); // 排队。
    int used=0,sum=0; // used 是已用时间，sum 是等待时间总和。
    for(int i=0;i<n;i++){cout<<p[i].number<<' ';sum+=used;used+=p[i].time;} // 输出队伍并计算等待。
    cout<<'\n'<<fixed<<setprecision(2)<<(double)sum/n<<'\n'; // 输出平均等待时间。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
4
3 1 2 1
```

输出：

```text
2 4 3 1 
1.75
```

**容易错：**等待时间不包括本人接水时间，平均值保留两位小数。

## 4. P1923 求第 k 小的数

![P1923 求第 k 小的数示意图](assets/walkthrough/P1923.webp)

题目来源：[洛谷 P1923](https://www.luogu.com.cn/problem/P1923)。详细要求以原题为准。

### 解题思路

从小到大排序后，最小数是第 0 小，所以答案在数组下标 k。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // 排序工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n,k; cin>>n>>k; // 读入个数和从 0 开始的名次。
    int a[5000000]; // 保存数字。
    for(int i=0;i<n;i++) cin>>a[i]; // 读入数字。
    sort(a,a+n); // 从小到大排序。
    cout<<a[k]<<'\n'; // 第 k 小就是下标 k。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
5 2
7 1 9 3 5
```

输出：

```text
5
```

**容易错：**不要写成下标 k-1；题目从 0 开始数。

## 5. P1048 采药

![P1048 采药示意图](assets/walkthrough/P1048.webp)

题目来源：[洛谷 P1048](https://www.luogu.com.cn/problem/P1048)。详细要求以原题为准。

### 解题思路

每株药只有采或不采两种选择。dp[t] 保存不超过 t 分钟的最大价值，时间倒序更新可避免重复采同一株。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // max 工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int T,M; cin>>T>>M; // 读入总时间和草药数。
    int dp[1001]={0}; // dp[t]：用不超过 t 分钟得到的最大价值。
    for(int i=0;i<M;i++){ // 逐株考虑草药。
        int time,value; cin>>time>>value; // 读入采摘时间和价值。
        for(int t=T;t>=time;t--) dp[t]=max(dp[t],dp[t-time]+value); // 倒序更新，保证一株只采一次。
    } // 所有草药处理结束。
    cout<<dp[T]<<'\n'; // 输出最大价值。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
70 3
71 100
69 1
1 2
```

输出：

```text
2
```

**容易错：**内层时间必须倒序；顺序错误会把一株药重复使用。

## 练习答案

P1271 输出排好的每张选票；P5740 同分选前面的学生；P1223 按接水时间从短到长排；P1923 第 0 小对应数组下标 0；P1048 必须倒序更新时间。
