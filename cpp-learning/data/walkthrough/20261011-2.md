# 多规则、多状态模拟 · 十道题逐行讲解

适合小学六年级的 C++ 学习讲义。第 1 课我们学会了"照题意一步步做"；这一课的模拟会同时转起好几条规则、好几个状态。把题面里互相缠绕的规则一条条拆开，把随时变化的状态一个个管住。

## 本课知识点

**状态要找全**：把"随时会变的信息"列成清单。P5661 里每张优惠票都有三个属性：面值、获得时刻、是否已用。每个状态对应一个变量、数组或队列。

**规则要分派**：题面有多条规则时，按事件发生顺序写主循环，每条规则一个 if 分支，先后优先级以题面为准。

**会管"会过期的东西"**：用队列维护先后顺序，用标记数组记"已用 / 作废"，过期对象从队头离开——票夹、传令、淘汰都靠它。

**有复杂度意识**：动手前先估算：循环要跑多少次？数据到 10 万时，盲目套循环会超时，"每步只做一点事"才稳。

建议先做 T01～T05（★★难度），T06～T10（★★★）作为进阶挑战。

## 1. P5661 公交换乘

![P5661 公交换乘示意图](assets/walkthrough/P5661.webp)

题目来源：[洛谷 P5661](https://www.luogu.com.cn/problem/P5661)。CSP-J 2019 T2，难度 ★★★。详细要求以原题为准。

### 解题思路

某旅游城市收集到 n 条乘车记录，按时间先后给出。乘地铁（op=0）：自己买票，同时获得一张面值等于票价、45 分钟有效的优惠票。乘公交（op=1）：先查票夹，找到最早获得的"未使用、未过期、面值够"的票就免费，否则花钱。

地铁 = 花钱 + 领票（永远不查票）；公交 = 先查票（能免则免），没票才花钱。

主循环按时间顺序逐条处理：
1. **先清队头**：队头的票已过期（时间差超过 45）或已使用，直接出队
2. **从早到晚找票**：在剩下的票里找第一张"没过期、没用过、面值够"的票
3. **找不到才花钱**：没有可用票时自己购票

票按获得时间排队，"从早到晚找"恰好就是队列顺序。队中间的过期票在扫描时逐张检查跳过，不立刻删除——打上 used 标记，等它挪到队头再真正出队。标记管"死活"，队列管"先后"。

复杂度：票有效期 45 分钟，队列里同时最多 46 张，每条记录约 46 次操作，O(46·n)，n = 10⁵ 时约 5×10⁶ 步。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
struct Ticket { // 定义一张优惠票信息卡。
    int face; // 票的面值。
    long long expiry; // 票的到期时刻。
    bool used; // 票是否已经使用过。
}; // 信息卡定义结束。
Ticket q[100005]; // 票夹队列：按获得时间从早到晚排列。
int head = 0, tail = 0; // 手写队列的队头和队尾下标。
int main() { // 程序开始。
    int n; // 乘车记录条数。
    cin >> n; // 读入记录条数。
    long long cost = 0; // 累计总花费，开 long long 防止溢出。
    for (int i = 0; i < n; i++) { // 按时间顺序逐条处理。
        int op; long long p, t; // op=0 地铁，op=1 公交；p 是票价，t 是时刻。
        cin >> op >> p >> t; // 读入当前记录。
        if (op == 0) { // ① 地铁：花钱 + 领票。
            cost += p; // 付出地铁票价。
            q[tail++] = { (int)p, t + 45, false }; // 领一张新票：面值 p，45 分钟后过期，未使用。
        } else { // ② 公交：查票三步。
            while (head < tail && (q[head].used || t > q[head].expiry)) head++; // 清队头：已用或过期的票出队。
            int pick = -1; // 记录找到哪张票，-1 表示没找到。
            for (int j = head; j < tail; j++) { // 从队头向队尾扫描。
                if (!q[j].used && t <= q[j].expiry && q[j].face >= p) { pick = j; break; } // 第一张未用、未过期、面值够的票。
            } // 扫描结束。
            if (pick != -1) q[pick].used = true; // 找到票：标记已用，免费乘车。
            else cost += p; // 没找到：自己花钱买票。
        } // 当前记录处理结束。
    } // 全部记录处理结束。
    cout << cost << endl; // 输出最少总花费。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
6
0 10 3
1 5 46
0 12 50
1 3 96
0 5 110
1 6 135
```

输出：

```text
36
```

**易错提醒：**过期条件是 t − t₀ ≤ 45，注意是"≤"；用过的票不能立刻出队（可能在队中间），标 used 即可；t 可达 10⁹，时间和花费都要开 long long。

**运行规模：**每条记录最多扫描 46 张票，总操作约 46×n ≈ 5×10⁶，1 秒内轻松通过。

## 2. P1190 接水问题

![P1190 接水问题示意图](assets/walkthrough/P1190.webp)

题目来源：[洛谷 P1190](https://www.luogu.com.cn/problem/P1190)。NOIP 2010 普及组，难度 ★★。详细要求以原题为准。

### 解题思路

m 个水龙头，n 名同学按编号顺序接水。前 m 人各占一个龙头，后面的人到达时站到"最早空出"的龙头（并列取编号小的）。

状态只有一个：finish[j] = j 号龙头当前这批人接完的时刻。新同学来了，扫 m 个龙头找 finish 最小的站上去，finish[j] += w[i]。最后答案 = max(finish[1..m])。

接水顺序就是输入顺序，不需要队列——用循环变量 i 就够了。打擂台用严格小于（finish[k] < finish[j]），并列时编号小的自动胜出。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
int w[10005], finish[105]; // w 保存每人接水量，finish 保存每个龙头的结束时刻。
int main() { // 程序开始。
    int n, m; // 同学人数和龙头数量。
    cin >> n >> m; // 读入两个人数。
    for (int i = 1; i <= n; i++) cin >> w[i]; // 读入每人的接水量。
    for (int i = 1; i <= m; i++) finish[i] = w[i]; // 前 m 人先各占一个龙头。
    for (int i = m + 1; i <= n; i++) { // 从第 m+1 人开始逐个补位。
        int j = 1; // 先假设 1 号龙头最早空出。
        for (int k = 2; k <= m; k++) { // 扫描其余龙头。
            if (finish[k] < finish[j]) j = k; // 严格小于：并列时编号小的保留。
        } // 找最早空出的龙头结束。
        finish[j] += w[i]; // 站上去接水，该龙头的结束时刻增加。
    } // 全部同学安排结束。
    int ans = 0; // 答案：所有龙头结束时刻的最大值。
    for (int i = 1; i <= m; i++) ans = max(ans, finish[i]); // 打擂台找最大值。
    cout << ans << endl; // 输出最后一人接完的时刻。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
5 3
4 4 1 2 1
```

输出：

```text
4
```

**易错提醒：**答案是所有窗口结束时间的最大值，不是等待时间之和；打擂台用严格小于，并列自动取编号小的窗口。

**运行规模：**n 人 × 每人扫 m 个窗口 = O(n·m) ≤ 10⁶ 次比较，毫秒级。

## 3. P1042 乒乓球

![P1042 乒乓球示意图](assets/walkthrough/P1042.webp)

题目来源：[洛谷 P1042](https://www.luogu.com.cn/problem/P1042)。NOIP 2003 普及组，难度 ★★。详细要求以原题为准。

### 解题思路

记录中 W 表示华华得一分，L 表示对手得一分，E 表示结束。一局结束条件：一方得分达到 base 分**且**领先至少 2 分——两个条件缺一不可。

同一场比赛分别按 11 分制和 21 分制输出，每局比分一行，末局不足一局也要输出，两种赛制之间恰好空一行。

把"结算一局"写成带参数的 work(base) 函数，一份逻辑跑两遍——规则差变成函数参数。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <string> // 使用字符串保存比赛记录。
using namespace std; // 可以直接使用标准工具的名字。
string s; // 保存整场比赛的逐球记录。
void work(int base) { // 按 base 分制结算并输出。
    int a = 0, b = 0; // 当前局双方得分。
    for (int i = 0; i < (int)s.size(); i++) { // 逐球扫描。
        if (s[i] == 'W') a++; else b++; // W 华华得分，L 对手得分。
        bool over = (a >= base && a - b >= 2) || (b >= base && b - a >= 2); // 达标且领先 2 分。
        if (over) { cout << a << ":" << b << "\n"; a = b = 0; } // 输出本局比分，清零开始下一局。
    } // 扫描结束。
    cout << a << ":" << b << "\n"; // 末局照输出（可能 0:0）。
} // 结算函数结束。
int main() { // 程序开始。
    char c; // 当前读到的字符。
    while (cin >> c && c != 'E') s += c; // 逐字符读入，自动跳过换行，读到 E 停止。
    work(11); // 先按 11 分制结算。
    cout << "\n"; // 两种赛制之间空一行。
    work(21); // 再按 21 分制结算。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
WWWWWWWWWWWWWWWWWWWW
WWLWE
```

输出：

```text
11:0
11:0
1:1

21:0
2:1
```

**易错提醒：**"达到 base 分"不等于局终，还要领先至少 2 分，"且"别写成"或"；末局不足 base 也要输出当前比分；两部分之间恰好一个空行。

**运行规模：**总球数有限（≪10⁶），每球 O(1) 判断，两遍扫描即可。

## 4. P1328 生活大爆炸版石头剪刀布

![P1328 石头剪刀布示意图](assets/walkthrough/P1328.webp)

题目来源：[洛谷 P1328](https://www.luogu.com.cn/problem/P1328)。NOIP 2014 普及组，难度 ★★。详细要求以原题为准。

### 解题思路

五种手势（0 剪刀、1 石头、2 布、3 蜥蜴人、4 斯波克），两两胜负关系共 10 条。A、B 各按自己的周期循环出招，每轮查表计分。

两个考点：
1. **5×5 胜负表**：wtab[x][y] = 1 表示 x 胜 y。查表 O(1)，不需要写十个 if。
2. **周期取模**：第 i 轮（从 0 起），A 出 a[i % NA]，B 出 b[i % NB]。周期不同没关系，取模自动回卷。

判分：if (wtab[x][y]) A 得分；else if (wtab[y][x]) B 得分；否则平局。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
int wtab[5][5] = { // 胜负表：wtab[x][y]==1 表示 x 胜 y。
    {0,0,1,1,0}, // 剪刀（0）：胜布（2）、蜥蜴人（3）。
    {1,0,0,1,0}, // 石头（1）：胜剪刀（0）、蜥蜴人（3）。
    {0,1,0,0,1}, // 布（2）：胜石头（1）、斯波克（4）。
    {0,0,1,0,1}, // 蜥蜴人（3）：胜布（2）、斯波克（4）。
    {1,1,0,0,0}  // 斯波克（4）：胜剪刀（0）、石头（1）。
}; // 胜负表结束。
int a[205], b[205]; // A 和 B 的出招周期。
int main() { // 程序开始。
    int n, na, nb; // 总轮数、A 的周期长度、B 的周期长度。
    cin >> n >> na >> nb; // 读入三个数。
    for (int i = 0; i < na; i++) cin >> a[i]; // 读入 A 的周期。
    for (int i = 0; i < nb; i++) cin >> b[i]; // 读入 B 的周期。
    int sa = 0, sb = 0; // 双方总得分。
    for (int i = 0; i < n; i++) { // 逐轮比赛。
        int x = a[i % na], y = b[i % nb]; // 取模得到本轮出招。
        if (wtab[x][y]) sa++; // x 胜 y：A 得分。
        else if (wtab[y][x]) sb++; // y 胜 x：B 得分。
        // 两个都不中就是平局，无人得分。
    } // 全部轮次结束。
    cout << sa << " " << sb << endl; // 输出双方总得分。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
10 5 6
0 1 2 3 4
0 3 4 2 1 0
```

输出：

```text
6 2
```

**易错提醒：**胜负表抄错一格全盘错——抄表时横竖对照题面；数组下标与手势编号都从 0 起，少一串 ±1 换算。

**运行规模：**N、NA、NB 均不超过 200，每轮 O(1) 查表，总共最多 200 轮。

## 5. P1003 铺地毯

![P1003 铺地毯示意图](assets/walkthrough/P1003.webp)

题目来源：[洛谷 P1003](https://www.luogu.com.cn/problem/P1003)。NOIP 2011 提高组，难度 ★★。详细要求以原题为准。

### 解题思路

n 张矩形地毯按编号顺序铺设，后铺的盖在先铺的上面。给定一点 (x, y)，求最上面是第几号地毯。

不用真的"叠"地毯——地毯之间只有一条规则：后铺的赢。从 1 到 n 顺序扫描，每张判断点是否被覆盖，命中就更新 ans = i。后铺的直接覆盖 ans，"最上面"自动成立。

判断条件：aᵢ ≤ x ≤ aᵢ+gᵢ 且 bᵢ ≤ y ≤ bᵢ+kᵢ，四个 ≤ 都不能少——踩在地毯边上也算"被覆盖"。坐标可达 10⁵，不要开二维格子画地图，逐张判断矩形是否含点即可。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
int a[10005], b[10005], g[10005], k[10005]; // 每张地毯的左下角坐标和 x/y 方向长度。
int main() { // 程序开始。
    int n; // 地毯张数。
    cin >> n; // 读入地毯张数。
    for (int i = 1; i <= n; i++) // 逐张读入。
        cin >> a[i] >> b[i] >> g[i] >> k[i]; // 读入第 i 张地毯的四个参数。
    int x, y; // 询问点的坐标。
    cin >> x >> y; // 读入询问点。
    int ans = -1; // 答案初值就是 -1（含 n=0 的情况）。
    for (int i = 1; i <= n; i++) { // 从第 1 张到第 n 张顺序扫描。
        if (a[i] <= x && x <= a[i] + g[i] && // x 被夹在 a 与 a+g 之间。
            b[i] <= y && y <= b[i] + k[i]) // y 被夹在 b 与 b+k 之间。
            ans = i; // 命中：更新为最上面的地毯编号。
    } // 全部地毯扫描结束。
    cout << ans << endl; // 输出答案。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
3
1 0 2 3
0 2 3 3
2 1 3 3
2 2
```

输出：

```text
3
```

**易错提醒：**边界含等号，四个 ≤ 一个不能少；x 方向是 a+g（不是 a+g−1）；n=0 时输出 -1，别让循环炸掉。

**运行规模：**O(n) 顺序扫描，n ≤ 10⁴，毫秒级。

## 6. P1563 玩具谜题

![P1563 玩具谜题示意图](assets/walkthrough/P1563.webp)

题目来源：[洛谷 P1563](https://www.luogu.com.cn/problem/P1563)。NOIP 2016 普及组，难度 ★★★。详细要求以原题为准。

### 解题思路

n 个玩具围成一圈，各有朝向（0 朝内、1 朝外）。医生从第 1 个玩具出发，执行 m 条指令：s=0 左数、s=1 右数，数 x 个。

方向判定一张 2×2 表就搞定：

| 玩具朝向 \ 指令 | 左数（s=0） | 右数（s=1） |
|---|---|---|
| 朝内（0） | 编号减小（同→减） | 编号增大（异→加） |
| 朝外（1） | 编号增大（异→加） | 编号减小（同→减） |

"同减异加"四个字。x 可达 10⁹，绕圈几十万次也是回到原地——先 x % n 再一步到位。减法可能变负，用 ((cur − x%n) % n + n) % n 保证非负回卷。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <string> // 使用字符串保存职业名。
using namespace std; // 可以直接使用标准工具的名字。
int dirn[100005]; // 每个玩具的朝向：0 朝内，1 朝外。
string job[100005]; // 每个玩具的职业名。
int main() { // 程序开始。
    int n, m; // 玩具数量和指令数量。
    cin >> n >> m; // 读入两个数量。
    for (int i = 0; i < n; i++) cin >> dirn[i] >> job[i]; // 读入每个玩具的朝向和职业。
    int cur = 0; // 当前停在第 0 号玩具（即第 1 个）。
    for (int i = 0; i < m; i++) { // 逐条执行指令。
        int s, x; // s=0 左数，s=1 右数；x 是要数的个数。
        cin >> s >> x; // 读入当前指令。
        if (dirn[cur] == s) // 同减：朝向与指令相同，逆着编号走。
            cur = ((cur - x % n) % n + n) % n; // 取模防溢出，+n 防负数，再取模回卷。
        else // 异加：朝向与指令不同，顺着编号走。
            cur = (cur + x) % n; // 加法取模即可。
    } // 全部指令执行结束。
    cout << job[cur] << endl; // 输出最终停在的玩具的职业名。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
7 3
0 singer
0 reader
0 mengbier
1 thinker
1 archer
0 writer
1 mogician
0 3
1 1
0 2
```

输出：

```text
writer
```

**易错提醒：**回卷公式 ((cur − x%n) % n + n) % n 四步缺一不可——内层取模防溢出、中间可能为负、+n 拉回非负、外层再 %n；x 可达 10⁹，真的一步一步数会 TLE。

**运行规模：**O(m) 条指令，每条 O(1)，n、m ≤ 10⁵，轻松通过。

## 7. P1518 两只塔姆沃斯牛

![P1518 两只塔姆沃斯牛示意图](assets/walkthrough/P1518.webp)

题目来源：[洛谷 P1518](https://www.luogu.com.cn/problem/P1518)。USACO 经典题，难度 ★★★。详细要求以原题为准。

### 解题思路

10×10 农场网格：F 农夫、C 牛、* 障碍、. 空地。两人同时行动：每分钟各朝当前方向走一格；前方出界或撞障碍则原地顺时针转向（上→右→下→左），这一分钟不前进。初始都朝上。

每分钟结束后：同格 → 输出分钟数；状态重复 → 输出 0（永不相遇）。

关键洞察：每人由"位置×方向"决定，10×10×4 = 400 种，两人组合 160000 种状态。状态一重复，之后全是重播——用六维数组 vis[10][10][4][10][10][4] 判重，约 160KB，开得下。

每分钟的固定顺序：先判相遇 → 再查 vis → 记 vis → 双方各走一步。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
char g[10][11]; // 农场地图，10 行每行 10 个字符加字符串结尾。
bool vis[10][10][4][10][10][4]; // 六维判重数组：农夫位置+方向、牛位置+方向。
int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1}; // 上右下左四个方向的行、列增量。
void step(int &x, int &y, int &d) { // 走一步：& 表示直接修改外面的变量。
    int nx = x + dx[d], ny = y + dy[d]; // 计算前方坐标。
    if (nx < 0 || nx > 9 || ny < 0 || ny > 9 || g[nx][ny] == '*') // 出界或撞障碍。
        d = (d + 1) % 4; // 原地顺时针转向，这一分钟不前进。
    else { x = nx; y = ny; } // 前方畅通：前进一格。
} // 走一步函数结束。
int main() { // 程序开始。
    int fx, fy, cx, cy, fd = 0, cd = 0; // 两人位置和方向，初始方向都是 0（上）。
    for (int i = 0; i < 10; i++) cin >> g[i]; // 读入 10 行地图。
    for (int i = 0; i < 10; i++) // 遍历地图找起点。
        for (int j = 0; j < 10; j++) { // 逐列检查。
            if (g[i][j] == 'F') { fx = i; fy = j; } // 找到农夫。
            if (g[i][j] == 'C') { cx = i; cy = j; } // 找到牛。
        } // 起点搜索结束。
    for (int t = 0; t <= 160000; t++) { // 最多 160000 分钟。
        if (fx == cx && fy == cy) { cout << t; return 0; } // 同格：输出分钟数，结束。
        if (vis[fx][fy][fd][cx][cy][cd]) { cout << 0; return 0; } // 状态见过：死循环，输出 0。
        vis[fx][fy][fd][cx][cy][cd] = true; // 记录当前状态。
        step(fx, fy, fd); // 农夫走一步。
        step(cx, cy, cd); // 牛走一步。
    } // 循环结束。
    cout << 0; return 0; // 超过上界仍未结束，输出 0。
} // 主函数结束。
```

### 自拟测试

输入：

```text
*...*.....
......*...
...*...*..
..........
...*.F....
*.....*...
...*......
..C......*
...*.*....
.*.*......
```

输出：

```text
49
```

**易错提醒：**判重次序不能错——先查相遇、再查 vis、记 vis、最后才走；转向口诀是"出界或撞障碍 → 原地转 90°"，别绕过障碍"滑行"；六维数组约 160KB，完全开得下。

**运行规模：**状态总数 160000，循环上界内必然出结果。

## 8. P2615 神奇的幻方

![P2615 神奇的幻方示意图](assets/walkthrough/P2615.webp)

题目来源：[洛谷 P2615](https://www.luogu.com.cn/problem/P2615)。NOIP 2015 普及组，难度 ★★★。详细要求以原题为准。

### 解题思路

n×n 矩阵（n 为奇数）按规则填 1..n²：1 填在第一行正中间；之后每个数填在前一个数的右上方，四条规则处理越界与冲突：

1. 第一行但不在最后一列 → 填最后一行、右一列
2. 最后一列但不在第一行 → 填第一列、上一行
3. 右上角 → 填正下方
4. 右上为空 → 填右上；已填 → 填正下方

四条规则互斥且覆盖所有情形，用 if / else if 链逐条翻译。判空直接问数组：a[x-1][y+1] == 0 即"没填过"。全程不用取模！

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
int a[45][45]; // 幻方矩阵，全局数组初值全 0 表示"未填"。
int main() { // 程序开始。
    int n; // 矩阵边长（奇数）。
    cin >> n; // 读入 n。
    int x = 1, y = (n + 1) / 2; // 1 填在第一行正中间。
    for (int k = 1; k <= n * n; k++) { // 依次填 1 到 n²。
        a[x][y] = k; // 当前数填在 (x, y)。
        if (x == 1 && y == n) x++; // ③ 右上角 → 正下方。
        else if (x == 1) x = n, y++; // ① 第一行 → 最后一行、右一列。
        else if (y == n) x--, y = 1; // ② 最后一列 → 上一行、第一列。
        else if (a[x-1][y+1] == 0) x--, y++; // ④ 右上方格为空 → 右上。
        else x++; // ④ 右上方格已填 → 正下方。
    } // 全部填完。
    for (int i = 1; i <= n; i++) // 逐行输出。
        for (int j = 1; j <= n; j++) // 逐列输出。
            cout << a[i][j] << (j == n ? "\n" : " "); // 行末换行，否则空格。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
3
```

输出：

```text
8 1 6
3 5 7
4 9 2
```

**易错提醒：**漏写 ③（右上角特判）是最常见丢分点——只写 ①② 的话，(1,n) 会同时"看起来"命中 ① 或 ②，越界访问 a[0] 或 a[n+1]；四条规则一个都不能少。

**运行规模：**总填数 ≤ 39² = 1521，O(n²) 轻松通过。

## 9. P7072 直播获奖

![P7072 直播获奖示意图](assets/walkthrough/P7072.webp)

题目来源：[洛谷 P7072](https://www.luogu.com.cn/problem/P7072)。CSP-J 2020 T2，难度 ★★★。详细要求以原题为准。

### 解题思路

选手按报名顺序逐一提交成绩（0..600）。每当第 i 人提交后，实时输出当前获奖分数线：p = max(1, w×i/100)，分数线 = 从高到低第 p 名的成绩。

值域只有 0..600 共 601 种——用桶计数 cnt[v] 保存每个分数的人数，每来一人 cnt[a]++ 是 O(1)。找分数线时从 600 往下逐档累加，第一次 seen ≥ p 的 v 就是答案。同分并列恰好由累加实现。

每人提交都重新排序？n ≤ 10⁵ 排不起——桶把"排序"变成"数人头"。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
int cnt[605]; // 桶：cnt[v] = 成绩 v 的人数。
int main() { // 程序开始。
    int n, w; // 选手人数和获奖率百分比。
    cin >> n >> w; // 读入两个数。
    for (int i = 1; i <= n; i++) { // 逐人提交成绩。
        int a; // 当前选手的成绩。
        cin >> a; // 读入成绩。
        cnt[a]++; // 入桶：O(1) 完成"插入"。
        int p = w * i / 100; // 获奖名额 = 当前人数 × 获奖率，整数除法自动向下取整。
        if (p < 1) p = 1; // 至少 1 人获奖。
        int seen = 0, ans = 0; // seen 累计已数过的人数，ans 记录分数线。
        for (int v = 600; v >= 0; v--) { // 从高分往低分数人头。
            seen += cnt[v]; // 加上这一档的人数。
            if (seen >= p) { ans = v; break; } // 数到第 p 个人时所在的档就是分数线。
        } // 分数线确定。
        cout << ans << "\n"; // 输出当前分数线。
    } // 全部选手处理结束。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
10 60
200 300 400 500 600 600 0 300 200 100
```

输出：

```text
200
300
400
400
400
500
400
400
300
300
```

**易错提醒：**p 是"当前人数 × w"再取整，不是总人数固定值；同分并列时第 p 名取较低分——累加 cnt 再判 seen ≥ p 恰好实现；内层循环最多 601 步，找到就 break。

**运行规模：**每人 O(1) 入桶 + 最多 601 步扫描，最坏 601×10⁵ ≈ 6×10⁷ 次加法，稳过。

## 10. P7912 小熊的果篮

题目来源：[洛谷 P7912](https://www.luogu.com.cn/problem/P7912)。CSP-J 2021 T4，难度 ★★★。详细要求以原题为准。

### 解题思路

n 个苹果排成一排，种类为 0 或 1。每一轮，把当前序列中每个"连续同类型段"的最左边一个苹果同时拿走，输出每轮拿走的编号。

段会变短、段会合并，段首也跟着变。关键思路：**先拍快照，轮末统一摘链**——本轮只处理轮初队列里的段头（快照 k 个），拿走的苹果先标记、本轮不摘链，等本轮全部判断完再统一摘除。这就是"同时"。

三件套：
1. **双向链表**（pre/nxt 数组）：摘掉一个苹果只影响左右邻居，O(1) 删除
2. **gone[] 标记**：已拿走的苹果跳过
3. **段头队列**：只放"可能成为段头"的编号，被拿苹果的右邻是下一个候选

每个苹果最多"入队两次"（初始段头 + 一次接棒），总工作量 O(n)。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
using namespace std; // 可以直接使用标准工具的名字。
const int N = 200005; // 苹果最大数量。
int a[N], pre[N], nxt[N], basket[N]; // 种类、前驱、后继、本轮拿走的列表。
bool gone[N]; // 标记苹果是否已被拿走。
int q[400005], head = 0, tail = 0; // 段头队列：每个苹果最多入队两次，开 2n。
int main() { // 程序开始。
    int n; // 苹果数量。
    cin >> n; // 读入苹果数量。
    for (int i = 1; i <= n; i++) { // 逐个读入苹果。
        cin >> a[i]; // 读入第 i 个苹果的种类。
        pre[i] = i - 1; nxt[i] = i + 1; // 初始化双向链表。
        if (i == 1 || a[i] != a[i-1]) q[tail++] = i; // 初始段头：第一个或与左边不同。
    } // 读入结束。
    while (head < tail) { // 队列非空就继续一轮。
        int k = tail - head, cnt = 0; // 快照：本轮只处理队列里已有的 k 个段头。
        for (int t = 0; t < k; t++) { // 逐个处理快照中的段头。
            int h = q[head++]; // 取出当前段头。
            if (gone[h] || (pre[h] >= 1 && a[pre[h]] == a[h])) continue; // 已拿或左边同类（不是段头）。
            basket[cnt++] = h; // 确认拿走，记入本轮列表。
            int r = nxt[h]; // 看右邻。
            if (r <= n && a[r] == a[h]) q[tail++] = r; // 右邻同类：接棒成为新段头，入队。
        } // 快照处理结束。
        for (int t = 0; t < cnt; t++) { // 轮末统一摘链 = "同时"拿走。
            int h = basket[t]; // 当前要摘掉的苹果。
            nxt[pre[h]] = nxt[h]; pre[nxt[h]] = pre[h]; // 双向链表 O(1) 删除。
            gone[h] = true; // 标记已拿走。
        } // 摘链结束。
        for (int t = 0; t < cnt; t++) // 逐个输出本轮拿走的编号。
            cout << basket[t] << (t == cnt - 1 ? "\n" : " "); // 最后一个换行，否则空格。
    } // 全部轮次结束。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
12
1 1 0 0 1 1 1 0 1 1 0 0
```

输出：

```text
1 3 5 8 9 11
2 4 6 12
7
10
```

**易错提醒：**轮 2 剩下 2 4 6 7 10 12，重新分段后 10 在段 [6,7,10] 的中间，不是段首，所以不拿——判断代码就是 pre[h] 的种类还和我一样则跳过；队列要开 2n，数组越界就 RE。

**运行规模：**每个苹果最多入队两次，总工作量 O(n)，n 最大约 2×10⁵。

## 常见错误门诊

| 症状 | 典型原因 | 对策 |
| --- | --- | --- |
| WA 答案错误 | 规则翻错、优先级乱 | 拿官方样例手推一遍，对照规则清单逐条核对 |
| RE 运行错误 | 越界、数组开小了 | 数组按数据上限再 +5；下标先判范围再用 |
| TLE 运行超时 | 全量重扫、复杂度爆 | 先估算 n × 循环层数，超过 10⁸ 就换队列、桶或链表 |
| 格式错误 | 空行空格、边界差一 | 逐字符对照样例输出；≤ 还是 ＜ 单独造数据测 |
