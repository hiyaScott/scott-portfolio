## 1. P1802 五倍经验日

![P1802 五倍经验日示意图](assets/walkthrough/P1802.webp)

### 题目在说什么

YYD 迷上了一款游戏，今天要打 `n` 场比赛（可以理解为打 `n` 局排位）。

每一局有两个结果：

- **赢了**：加 `win[i]` 点经验
- **输了**：加 `lose[i]` 点经验（赢了给的经验更多，所以大家都想赢）

但是赢比赛要"吃药"——第 `i` 局如果想赢，**至少要消耗 `use[i]` 个药**。药总共只有 `x` 个，用完就没了。

问：经验最多能拿多少？最后答案要 **×5**（因为今天官方开"五倍经验活动"）。

**输入**：第一行 `n` 和 `x`；接下来 `n` 行，每行三个数 `lose[i]`、`win[i]`、`use[i]`。

### 该怎么想

把问题翻译成生活语言：

> 你手里有 `x` 个硬币。要连续挑战 `n` 个关卡。每个关卡你有两条路：
> ① 乖乖挨打，白拿 `lose[i]` 经验，不花钱；
> ② 砸 `use[i]` 个硬币买装备打赢，拿更多经验 `win[i]`。
> 问怎么花钱最划算。

这就是经典的 **背包问题**：背包容量 = `x` 个药，每个物品 = 一场比赛，"花掉的药"就是重量，"拿到的经验"就是价值。

我们设 `f[j]` 表示：**打到现在为止，一共花了 `j` 个药，最多能攒多少经验**。

处理第 `i` 场比赛时，只有两种选择：

| 选择 | 花的药 | 得的经验 | 状态怎么变 |
|------|--------|----------|------------|
| 输掉这一场 | 0 | `lose[i]` | `f[j] + lose[i]` |
| 赢下这一场 | `use[i]` | `win[i]` | `f[j-use[i]] + win[i]` |

取两者中大的那个就行。

**注意**：数组要倒着从大到小循环（这是背包问题的祖传套路），保证每个药不会被同一场比赛重复使用。最后在所有 `f[j]` 里挑最大值，乘 5 输出。

还有一个坑：经验加起来最大约 `10^9`，乘 5 更大，普通的 `int` 装不下，要用 `long long`。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, x;
int lose[1005], win[1005], use[1005];
long long f[1005];

int main() {
    cin >> n >> x;
    for (int i = 1; i <= n; i++) {
        cin >> lose[i] >> win[i] >> use[i];
    }

    for (int i = 1; i <= n; i++) {
        for (int j = x; j >= use[i]; j--) {
            f[j] = max(f[j] + lose[i], f[j - use[i]] + win[i]);
        }
        for (int j = use[i] - 1; j >= 0; j--) {
            f[j] += lose[i];
        }
    }

    long long ans = 0;
    for (int j = 0; j <= x; j++) {
        ans = max(ans, f[j]);
    }
    cout << 5 * ans << endl;
    return 0;
}
```

### 逐行讲解

**第一部分：头文件和变量**

- `#include <bits/stdc++.h>` —— 一个"万能头文件"，把竞赛常用的所有工具库一次性全引进来，写竞赛时图省事。
- `using namespace std;` —— 告诉编译器"我要用标准库里的东西"，不写这句的话，`cin`、`cout` 前面都要加 `std::`，太麻烦。
- `int n, x;` —— `n` 是比赛场数，`x` 是药的总数。
- `int lose[1005], win[1005], use[1005];` —— 三个数组，分别记下每场"输了得多少、赢了得多少、至少要几个药"。开 1005 是因为 n 最大 1000，多开 5 个防手滑。
- `long long f[1005];` —— 核心数组！`f[j]` 的意思是"花了 j 个药时最多攒下的经验"。用 `long long` 是因为它可能存很大的数。

**第二部分：读入**

- `cin >> n >> x;` —— 先读场数和药数。
- `for (int i = 1; i <= n; i++) cin >> lose[i] >> win[i] >> use[i];` —— 一场一场把三个数据读进来，存在第 i 个格子里。注意我们从 1 开始数，不用第 0 格。

**第三部分：核心循环（最重要！）**

- `for (int i = 1; i <= n; i++)` —— 外层循环：一场一场处理。i 表示"现在正在考虑第 i 场"。
- `for (int j = x; j >= use[i]; j--)` —— 内层循环：**j 从 x 往下数到 use[i]**。j 表示"假设我总共要花 j 个药"。倒着走是背包问题的规定动作，下面解释。
- `f[j] = max(f[j] + lose[i], f[j - use[i]] + win[i]);` —— 本题的精华，拆开看：
  - `f[j] + lose[i]`：第 i 场**输掉**，不花药，白拿输的经验；
  - `f[j - use[i]] + win[i]`：第 i 场**赢下**，从之前只花了 `j - use[i]` 个药的状态转移过来，再加上赢的经验；
  - `max(...)`：两条路哪条经验多走哪条。
  - 为什么 j 要倒着走？如果正着走，当我们算 `f[j]` 时，`f[j - use[i]]` 可能**已经被这一场更新过了**，等于同一场比赛的药被用了两次——这在 01 背包里是大忌。倒着走，小的 j 还没被更新，`f[j-use[i]]` 里存的永远是"上一场"的旧数据，保证一场比赛的药最多用一次。
- `for (int j = use[i] - 1; j >= 0; j--) f[j] += lose[i];` —— 药不够怎么办？比如 j 比 `use[i]` 小，想赢也赢不了，那这一场**只能输**，老老实实加上 `lose[i]`。

**第四部分：收尾**

- `long long ans = 0;` —— 准备记录最终答案。
- `for (int j = 0; j <= x; j++) ans = max(ans, f[j]);` —— 不一定要花光所有药！所以在"花了 0 个药"到"花光 x 个药"所有结果里挑最大的。
- `cout << 5 * ans << endl;` —— 五倍经验日，乘 5 输出。

### 小结

这题学会了：**背包问题**的套路——把"资源上限"想成书包容量，把"每个选择"想成放不放某个物品，`f[j]` 倒序更新。后面第 2 题还是它。

## 2. P1049 装箱问题

![P1049 装箱问题示意图](assets/walkthrough/P1049.webp)

### 题目在说什么

你有一个容量为 `V` 的箱子，面前有 `n` 件物品，每件物品有一个体积（注意：这道题的"体积"就是它的全部属性，没有别的价值）。

你可以挑任意几件塞进箱子（也可以一件都不塞），目标是让**箱子剩下的空隙最小**。

**输入**：第一行 `V`（箱子容量），第二行 `n`（物品数），接下来 `n` 行每行一个数表示该物品体积。

### 该怎么想

和第 1 题一样，还是背包。这次更简单——因为每件物品的"体积"就是"价值"：塞进去多少体积，箱子就满多少。

设 `dp[j]` = **容量为 j 的箱子，最多能塞进去多少体积**。

对每件物品，两个选择：

- 不塞：`dp[j]` 保持原样；
- 塞：`dp[j] = dp[j - v[i]] + v[i]`（先腾出一个 v[i] 大小的位置，再把这件放进去）。

取大的那个。全部处理完后，`dp[V]` 就是容量 V 能装下的最大体积，答案是 `V - dp[V]`。

内层依然**倒序**，理由和第 1 题一模一样。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int V, n;
int v[35];
int dp[20005];

int main() {
    cin >> V >> n;
    for (int i = 1; i <= n; i++) {
        cin >> v[i];
    }

    for (int i = 1; i <= n; i++) {
        for (int j = V; j >= v[i]; j--) {
            dp[j] = max(dp[j], dp[j - v[i]] + v[i]);
        }
    }

    cout << V - dp[V] << endl;
    return 0;
}
```

### 逐行讲解

- `int V, n;` —— `V` 是箱子容量，`n` 是物品数量。
- `int v[35];` —— 存每件物品的体积。n 最多 30，开 35 够用。
- `int dp[20005];` —— `dp[j]` 表示容量 j 最多能装多少。V 最大 20000，所以开 20005。
- `cin >> V >> n;` —— 读箱子和物品数。
- `for (...) cin >> v[i];` —— 逐个读物品体积。
- `for (int i = 1; i <= n; i++)` —— 外层：一件一件考虑物品。
- `for (int j = V; j >= v[i]; j--)` —— 内层：j 表示"假设箱子容量是 j"，**从 V 倒着数到 v[i]**。
  - 为什么下界是 `v[i]`？如果连这件物品都塞不下（j 比 v[i] 还小），那讨论"塞它"就没有意义，直接跳过。
- `dp[j] = max(dp[j], dp[j - v[i]] + v[i]);` —— 又是二选一：
  - `dp[j]`：不塞第 i 件，维持现状；
  - `dp[j - v[i]] + v[i]`：塞第 i 件——先把容量 j 里划出 v[i] 的空位给前面的物品用（它们的成果存在 `dp[j-v[i]]` 里），再加上这次的 v[i]。
  - 同样是倒序更新，防止同一件物品被塞进去好几次。
- `cout << V - dp[V] << endl;` —— 总容量减去能装的最大体积，剩下的就是空隙。

### 小结

和第 1 题是亲兄弟。区别是：第 1 题"赢/输"两种选择对应"花钱/不花"，这题"塞/不塞"。背包问题的公式 `dp[j] = max(dp[j], dp[j-重量] + 价值)` 一定要背下来，万变不离其宗。

## 3. P1554 梦中的统计

![P1554 梦中的统计示意图](assets/walkthrough/P1554.webp)

### 题目在说什么

奶牛 Bessie 半梦半醒地数数，从 `M` 一直数到 `N`。它好奇心很重：数过的这些数里，**数码 0~9 每个数字一共出现了多少次**？

比如从 129 数到 137：129、130、131……137。你把它们全部写出来数一数，就会发现 0 出现了 1 次、1 出现了 10 次……

**输入**：一行两个数 `M` 和 `N`。

**输出**：十个数，依次是 0、1、2……9 出现的次数。

### 该怎么想

这题不用想复杂！题目偷偷告诉我们一个秘密（在"数据范围"里）：**N − M 最大只有 500000**。

也就是说，从 M 到 N 最多 50 万个数。就算一个数一个数地数，50 万次，对电脑来说就是一眨眼的事（一秒能跑上亿次）。

所以对每个数，我们用"**拆数法**"把它的每一位抠出来：

- `t % 10` → 得到个位数（比如 137 % 10 = 7）
- `t /= 10` → 把个位砍掉（137 变成 13）
- 重复直到 `t` 变成 0

每抠出一位，就把对应数字的计数器加一。准备 10 个计数器（下标 0~9）正好对应 0~9。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int m, n;
long long cnt[10];

int main() {
    cin >> m >> n;
    for (int i = m; i <= n; i++) {
        int t = i;
        while (t > 0) {
            cnt[t % 10]++;
            t /= 10;
        }
    }
    for (int d = 0; d <= 9; d++) {
        cout << cnt[d] << " ";
    }
    cout << endl;
    return 0;
}
```

### 逐行讲解

- `int m, n;` —— 起点 M 和终点 N。
- `long long cnt[10];` —— 10 个计数器，`cnt[0]` 记 0 出现几次、`cnt[1]` 记 1 出现几次……以此类推。50 万个数、每个数最多 10 位，总次数最多约 500 万，`int` 其实也够，但开 `long long` 更保险。
- `for (int i = m; i <= n; i++)` —— 外层：从 M 遍历到 N，每个数都处理一遍。
- `int t = i;` —— 复制一份 i 到 t。因为我们接下来要不断砍 t 的末位，**不能动 i 本身**（i 还要用来控制循环）。
- `while (t > 0)` —— 只要 t 还没被砍光，就继续拆。比如 t = 137：137 → 13 → 1 → 0，循环 3 次，正好三位数。
- `cnt[t % 10]++;` —— 核心！`t % 10` 拿到 t 的个位数（拆出来的那一位），用它当下标，给对应计数器加 1。妙处在于：**数组下标正好就是数字本身**，不需要任何判断。
- `t /= 10;` —— 把个位砍掉，比如 137 / 10 = 13（小数部分自动舍弃）。下一轮继续拆 13 的个位。
- `for (int d = 0; d <= 9; d++) cout << cnt[d] << " ";` —— 按顺序输出 10 个计数器的值，中间用空格隔开。
- `cout << endl;` —— 最后换行，好习惯。

### 小结

这题学会了：**拆数法**（`%10` 取位、`/10` 砍位）和"**用数组下标当计数器**"——遇到"统计每种东西出现几次"的题目，第一时间想到这个配合。

## 4. P1918 保龄球

![P1918 保龄球示意图](assets/walkthrough/P1918.webp)

### 题目在说什么

DL 打保龄球。球道上一共有 `n` 个位置，每个位置摆着一些瓶子，并且**每个位置的瓶子数量都不一样**（有的位置 3 个、有的 7 个、有的 25 个……没有重复）。

DL 的力气是固定的：他想打倒 `m` 个瓶子，就必须站在"**正好有 m 个瓶子的那个位置**"发球。问你这个位置是几号；如果一个位置都没有，输出 0。

这样的询问会有 `Q` 次。

**输入**：第一行 `n`；第二行 n 个数（第 i 个数 = 第 i 个位置的瓶子数）；第三行 `Q`；接下来 Q 行每行一个 `m`。

**输出**：对每个 m，输出对应位置编号，找不到输出 0。

### 该怎么想

这题本质是"**查字典**"：我们要反复查询"瓶子数 m 对应的位置是几号"。

方法（排序 + 二分查找）：

1. 把每个位置的（瓶子数， 位置编号）打包成一对，**按瓶子数从小到大排序**。排完序后，瓶子数就变成从小到大排好的一列，方便我们查。
2. 每次询问 m，用**二分查找**：每次都看中间位置的瓶子数——
   - 正好等于 m → 找到了，输出它配对的位置编号；
   - 比 m 大 → 说明目标在左半边，去左边找；
   - 比 m 小 → 去右边找。
3. 左右指针撞在一起了还没找到，输出 0。

二分查找每查一次，候选范围就缩小一半，10 万个位置最多查 17 次，比一个一个翻快得多。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, Q;
pair<int, int> a[100005];

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i].first;
        a[i].second = i;
    }
    sort(a + 1, a + n + 1);

    cin >> Q;
    while (Q--) {
        int m;
        cin >> m;
        int lo = 1, hi = n, ans = 0;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (a[mid].first == m) {
                ans = a[mid].second;
                break;
            } else if (a[mid].first > m) {
                hi = mid - 1;
            } else {
                lo = mid + 1;
            }
        }
        cout << ans << endl;
    }
    return 0;
}
```

### 逐行讲解

- `int n, Q;` —— n 个位置、Q 次询问。
- `pair<int, int> a[100005];` —— 重点来了！`pair` 是 C++ 自带的"二人组"容器，可以把两个数绑在一起。这里 `a[i].first` 存瓶子数，`a[i].second` 存位置编号。为什么要绑定？因为排完序后顺序变了，我们必须记住每个瓶子数**原来**是几号位置。
- `cin >> a[i].first; a[i].second = i;` —— 读入瓶子数的同时，顺手把"它是第 i 个位置"记下来。
- `sort(a + 1, a + n + 1);` —— 排序！`pair` 默认先按 `.first` 排，`.first` 相同再比 `.second`。所以这行之后，瓶子数从小到大排好了。（`a+1` 到 `a+n` 是因为我们用 1~n 号，第 0 格没用。）
- `cin >> Q;` 然后 `while (Q--)` —— Q 次询问。`Q--` 的意思是"用完一次减一"，循环 Q 次后自动停下，是竞赛里常见写法。
- `int lo = 1, hi = n, ans = 0;` —— 二分准备：`lo` 是查找区间左端，`hi` 是右端，`ans` 先默认 0（意味着"还没找到"）。
- `while (lo <= hi)` —— 只要区间还没缩空，就继续找。
- `int mid = (lo + hi) / 2;` —— 取区间正中间的元素。
- `if (a[mid].first == m)` —— 正中目标！把配对的位置编号存进 ans，然后 `break` 跳出循环。
- `else if (a[mid].first > m) hi = mid - 1;` —— 中间的比目标大，说明目标（如果有的话）在**左边**，把右边界挪到 mid 左边。
- `else lo = mid + 1;` —— 中间的比目标小，目标在**右边**，把左边界挪到 mid 右边。
- `cout << ans << endl;` —— 找到了就输出位置，没找到 ans 还是 0，正好符合题目要求。

### 小结

学会了：**pair 绑定两个数** + **sort 排序** + **二分查找**。二分查找的核心口诀：每次砍一半——"大了往左，小了往右"。这三个工具以后会用得非常频繁。

## 5. P2241 统计方形

![P2241 统计方形示意图](assets/walkthrough/P2241.webp)

### 题目在说什么

给你一个 `n × m` 的方格棋盘（比如 2 行 3 列，共 6 个小格子）。请你数一数：

1. 棋盘里一共能框出多少个**正方形**？
2. 一共能框出多少个**长方形**？（注意：这里的长方形**不包括正方形**，正方形和长方形分开数）

**输入**：一行两个数 `n`、`m`。**输出**：正方形个数、长方形个数。

样例：2 3 → 输出 `8 10`。可以拿纸笔画一画验证。

### 该怎么想

用数学规律数，比一个一个格子枚举快得多（n、m 最大 5000，四重循环会超时）。

**第一步：数正方形。**

边长为 1 的正方形：每行有 n 个位置、每列 m 个位置？不，正确地说——边长 1 的有 `n × m` 个；边长 2 的有 `(n-1) × (m-1)` 个（每边都要空出一格，能放的位置各少 1）；边长 3 的有 `(n-2) × (m-2)` 个……边长最大是 `min(n, m)`（不能超过较短的那条边）。

所以：

> 正方形总数 = Σ (n−k+1) × (m−k+1)，k 从 1 到 min(n, m)

**第二步：数"所有矩形"。**

矩形只要 4 条边就行：横着选 2 条线，竖着选 2 条线。n×m 的棋盘有 `n+1` 条横线、`m+1` 条竖线。横线里任选 2 条有 (1+2+…+n) = n(n+1)/2 种选法，竖线同理 m(m+1)/2 种。相乘：

> 矩形总数 = n(n+1)/2 × m(m+1)/2 = n×(n+1)×m×(m+1) / 4

**第三步：减法。**

> 长方形 = 矩形总数 − 正方形数

**最后一个大坑**：5000×5001×5000×5001 这个数大到离谱（约 10^15），`int` 完全装不下，必须全程用 `long long`。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m;
    cin >> n >> m;

    long long square = 0;
    for (long long i = 1; i <= min(n, m); i++) {
        square += (n - i + 1) * (m - i + 1);
    }

    long long total = n * (n + 1) * m * (m + 1) / 4;
    cout << square << " " << total - square << endl;
    return 0;
}
```

### 逐行讲解

- `long long n, m;` —— 从读入就用 long long，不然后面乘法分分钟爆掉。
- `cin >> n >> m;` —— 读棋盘尺寸。
- `long long square = 0;` —— 正方形计数器清零。
- `for (long long i = 1; i <= min(n, m); i++)` —— i 代表"当前正在数的正方形边长"。`min(n, m)` 取 n 和 m 中较小的那个——边长最大就这么大。
- `square += (n - i + 1) * (m - i + 1);` —— 边长为 i 的正方形，横向能放 `n - i + 1` 个位置（整排有 n 格，边长占 i 格，起点有 n−i+1 种选法），纵向能放 `m - i + 1` 个，乘起来就是边长 i 的全部数量，累加进 square。
- `long long total = n * (n + 1) * m * (m + 1) / 4;` —— 矩形总数公式。`/4` 放最后除，保证先做乘法再整除，减少误差。
- `cout << square << " " << total - square << endl;` —— 先输出正方形数，空格，再输出"矩形总数 − 正方形"（即纯长方形数）。

### 小结

这题是"**数学规律 + 防止爆 int**"的典型。见到"数图形个数"先想公式；见到大数字先想 `long long`。样例 2 3 可以自己验证：正方形 = 2×3 + 1×2 = 8 ✓，矩形总数 = 2×3×3×4/4 = 18，长方形 = 18 − 8 = 10 ✓。

## 6. P1087 FBI 树

![P1087 FBI树示意图](assets/walkthrough/P1087.webp)

### 题目在说什么

给一个长度为 `2^N` 的 01 字符串（比如 N=3 时长度是 8）。

把这样的串分三类：

- **B 串**：全是 0
- **I 串**：全是 1
- **F 串**：0 和 1 都有

我们用这个串建一棵二叉树，规则是：

1. 整串对应树根，树的类型 = 整串的类型；
2. 如果串长度大于 1，就**从中间对半劈开**，左半边建左子树、右半边建右子树；
3. 一直劈到不能再劈——每个叶子就是一个字符：单独的 0 是 B，单独的 1 是 I。

建好之后，按**后序遍历**的顺序输出每个节点的字母（后序 = 先左子树、再右子树、最后根）。

样例：`3` 和 `10001011` → 输出 `IBFBBBFIBFIIIFF`。

### 该怎么想

不用真的画一棵树！观察规律：**树的过程就是"不断对半切区间"**，这正是**递归**最擅长的事。

设计一个函数 `build(l, r)`，负责处理区间 `[l, r]`（表示 s 串里下标 l 到 r 这一段）：

1. 如果 `l < r`（这段还能劈）：
   - 先 `build(l, mid)` 建好并输出左子树的一切；
   - 再 `build(mid+1, r)` 建好并输出右子树的一切；
2. 然后统计 `[l, r]` 里 0 和 1 各有多少个：
   - 两种都有 → 输出 `F`
   - 只有 0 → 输出 `B`
   - 只有 1 → 输出 `I`

看出来了吗？**先递归左右、最后输出自己——这正是"后序遍历"的定义**。我们连树都不用建，递归本身就把树的形状走了一遍。

### 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
string s;

void build(int l, int r) {
    if (l < r) {
        int mid = (l + r) / 2;
        build(l, mid);
        build(mid + 1, r);
    }
    int cnt0 = 0, cnt1 = 0;
    for (int i = l; i <= r; i++) {
        if (s[i] == '0') cnt0++;
        else cnt1++;
    }
    if (cnt0 && cnt1) cout << "F";
    else if (cnt0) cout << "B";
    else cout << "I";
}

int main() {
    cin >> n >> s;
    build(0, (int)s.size() - 1);
    cout << endl;
    return 0;
}
```

### 逐行讲解

**第一部分：变量与函数声明**

- `int n; string s;` —— `n` 是指数；`s` 是字符串，专门存那串 01。用 `string` 而不是字符数组，方便直接用 `s[i]` 取下标。
- `void build(int l, int r)` —— 声明一个"没有返回值"的函数 `build`，参数 `l`、`r` 表示"现在要处理 s 的第 l 到第 r 位"。

**第二部分：递归主体（最难，慢慢看）**

- `if (l < r)` —— 这段长度超过 1 吗？超过才需要"劈开"。如果 l == r，说明只剩一个字符，是叶子节点，直接跳到输出部分。
- `int mid = (l + r) / 2;` —— 算中点。比如 l=0、r=7，mid=3，左半 [0,3]、右半 [4,7]。
- `build(l, mid);` —— **递归**：先把左半边的树全部建好并输出完。
- `build(mid + 1, r);` —— **递归**：再把右半边的树全部建好并输出完。
  - 注意这两行的先后顺序：左子树的所有字母输出完了，才轮到右子树。这就是后序遍历"先左后右"的体现。
- `int cnt0 = 0, cnt1 = 0;` —— 准备两个计数器。
- `for (int i = l; i <= r; i++)` —— 把这段区间里每个字符都检查一遍。
- `if (s[i] == '0') cnt0++; else cnt1++;` —— 是 0 就加 cnt0，否则加 cnt1。
- `if (cnt0 && cnt1) cout << "F";` —— 两个计数器都不是 0（&& 表示"并且"），说明 0 和 1 都有 → 输出 F。
- `else if (cnt0) cout << "B";` —— 只有 0 → 输出 B。
- `else cout << "I";` —— 剩下的可能只有 1（这段至少有一个字符，所以 cnt0、cnt1 不可能同时为 0）→ 输出 I。

**第三部分：主函数**

- `cin >> n >> s;` —— 读指数和 01 串。
- `build(0, (int)s.size() - 1);` —— 从整串开始递归。`s.size()` 是字符串长度（这里是 `2^n`），下标从 0 到 `长度-1`，所以右端点是 `s.size() - 1`。
- `cout << endl;` —— 全部输出完换行。

**再用样例走一遍**：`10001011`，build(0,7) → 先劈成 `1000` 和 `1011`；`1000` 又劈成 `10`、`00`……一路切到单字符。叶子 `1`→I、`0`→B、`0`→B、`0`→B，它们合起来的 `10` 是 F、`00` 是 B，`1000` 是 F……最后拼出 `IBFBBBFIBFIIIFF`，和样例一模一样。

### 小结

学会了：**递归函数自己调用自己** + **后序遍历**（先左、再右、最后自己）。所有"不断对半分"的题目——折半查找、归并排序、线段树——都是这个套路的影子。
