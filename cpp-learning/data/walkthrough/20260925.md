## 1. P7071 优秀的拆分

### 题意变简单

把一个数拆成若干个**不同的** `2 的正整数次幂`，例如：

```text
10 = 8 + 2
```

其中 `8 = 2³`、`2 = 2¹`，所以可以。

所有能用的数都是偶数：`2、4、8、16……`。偶数加偶数仍是偶数，所以输入若是奇数，一定无解。

### 思路

从最大的 2 的幂开始试。只要它不超过剩余数字，就输出它，再从剩余数字里减掉它。

### 代码

```cpp
#include <iostream>                 // 使用 cin 读入数据、cout 输出答案
using namespace std;                // 后面可以直接写 cin、cout，不必写 std::cin

int main() {                        // 程序从 main 这里开始运行
    int n;                          // n 是题目给我们的数字
    cin >> n;                       // 从键盘读入 n

    if (n % 2 == 1) {               // n 除以 2 余 1，说明 n 是奇数
        cout << -1 << endl;         // 奇数不能由若干个偶数相加得到，所以输出 -1
        return 0;                   // 已经得到答案，立刻结束程序
    }

    for (int power = 8388608; power >= 2; power /= 2) { // 从大的 2 的幂试到小的
        if (n >= power) {            // 如果剩下的 n 够减去当前这个 2 的幂
            cout << power << ' ';    // 输出它，表示拆分时选中了它
            n = n - power;           // 从剩余数字中减掉它，继续拆后面的部分
        }
    }

    return 0;                        // 程序正常结束
}
```

### 逐行理解

- `n % 2 == 1`：`n` 除以 2 后余 1，说明 `n` 是奇数。
- `8388608` 是不超过题目最大范围的一个很大的 2 的幂。
- `power /= 2`：每次把 `power` 除以 2，例如 `16 → 8 → 4 → 2`。
- `n >= power`：剩余数字够大，就拿走这个 `power`。

## 2. P1008 三连击

### 思路

第一个三位数设为 `x`，那么另外两个一定是 `2x` 和 `3x`。只需从小到大尝试 `x`，检查 `x、2x、3x` 的九个数字是否刚好是 1 到 9 各一次。

### 代码

```cpp
#include <iostream>                         // 使用 cout 输出答案
using namespace std;                        // 使用标准命名空间

int main() {                                // 程序开始
    for (int x = 123; x <= 329; x++) {      // 把第一个三位数 x 从小到大一个个试
        int y = x * 2;                       // 第二个数必须是 x 的 2 倍
        int z = x * 3;                       // 第三个数必须是 x 的 3 倍

        int all = x * 1000000 + y * 1000 + z; // 把三个三位数拼成一个九位数

        int used[10] = {};                   // used[d] 记录数字 d 是否已经出现过；开始全是 0
        bool ok = true;                      // 先假设这组数是答案

        for (int i = 0; i < 9; i++) {        // 九位数里一共有 9 个数字，要检查 9 次
            int digit = all % 10;            // 取出 all 最右边的一位，例如 123 的最右位是 3

            if (digit == 0 || used[digit] == 1) { // 出现 0，或者某个数字重复，都不合题意
                ok = false;                  // 把“是答案”的标记改成“不是答案”
            }

            used[digit] = 1;                 // 记住这个数字已经出现过
            all = all / 10;                  // 删掉最右边一位，准备检查下一位
        }

        if (ok) {                            // 九位数中没有 0，也没有重复数字
            cout << x << ' ' << y << ' ' << z << endl; // 输出这一组答案
        }
    }

    return 0;                                // 所有 x 都试完，程序结束
}
```

### 重要提醒

这题没有输入。`x` 最大只能到 329，因为 `330 × 3 = 990`，再大就不可能得到三位数。

`used[10]` 像十个小格子：`used[5] = 1` 表示数字 5 已经出现过。遇到 0 或重复数字，就不是答案。

## 3. P1614 爱与愁的心痛

### 思路

从每一个可能的起点开始，直接加后面的连续 `m` 个数，记录最小的和。

题目 `n` 最多只有 3000，这个直接做的方法可以通过。

### 代码

```cpp
#include <iostream>                         // 使用 cin 和 cout
using namespace std;                        // 使用标准命名空间

int main() {                                // 程序开始
    int n, m;                               // n 是总数，m 是每次要连续选几个数
    cin >> n >> m;                          // 读入 n 和 m

    int a[3005];                            // a[i] 存第 i 个刺痛值

    for (int i = 1; i <= n; i++) {         // 从第 1 个数读到第 n 个数
        cin >> a[i];                        // 读入并保存第 i 个刺痛值
    }

    int answer = 1000000000;                // 先放一个非常大的数，方便后面找更小的和

    for (int start = 1; start <= n - m + 1; start++) { // 枚举连续 m 个数的起点
        int sum = 0;                        // 每换一个起点，新的这一段总和从 0 开始

        for (int j = start; j < start + m; j++) { // 从起点开始，连续拿 m 个数
            sum = sum + a[j];               // 把当前这个数加进这一段的总和
        }

        if (sum < answer) {                 // 如果刚算出的和比以前最小和还小
            answer = sum;                   // 更新答案
        }
    }

    cout << answer << endl;                 // 输出所有连续 m 个数中最小的总和
    return 0;                               // 程序正常结束
}
```

### 小例子

若 `m = 3`，就依次加：第 1~3 个、第 2~4 个、第 3~5 个……每次都是连续三个。

`n - m + 1` 是最后一个允许的起点。比如一共有 5 个数、每次选 3 个，最后只能从第 3 个数开始。

## 4. P1102 A-B 数对

### 思路

要满足：

```text
A - B = C
```

如果已经知道 `A`，就可以算出：

```text
B = A - C
```

所以我们用 `map` 当作“数字出现次数记录本”。例如 `count[7] = 3` 代表数字 7 出现了 3 次。

### 代码

```cpp
#include <iostream>                         // 使用 cin、cout
#include <map>                              // 使用 map 这个“按数字记次数”的记录本
using namespace std;                        // 使用标准命名空间

int main() {                                // 程序开始
    int n;                                  // n 是数列中数字的个数
    long long c;                            // c 是题目中的差；用 long long 防止数字太大
    cin >> n >> c;                          // 读入 n 和 c

    long long a[200005];                    // 保存原来的全部数字
    map<long long, long long> count;        // count[x] 表示数字 x 一共出现过几次

    for (int i = 0; i < n; i++) {           // 读入 n 个数字
        cin >> a[i];                         // 保存第 i 个数字
        count[a[i]]++;                       // 这个数字出现次数加 1
    }

    long long answer = 0;                   // answer 用来数符合条件的数对

    if (c == 0) {                           // 差是 0 时，两个数必须相同
        for (auto item : count) {           // 一个一个查看“某个数字出现了几次”
            long long howMany = item.second; // 取出这个数字的出现次数
            answer = answer + howMany * (howMany - 1) / 2; // 从这些位置中任选两个位置
        }
    } else {                                // 差不是 0 时，按 A - B = c 来找 B
        for (int i = 0; i < n; i++) {       // 把 a[i] 当作 A，轮流尝试每一个位置
            long long need = a[i] - c;      // 算出它需要的 B 是多少
            answer = answer + count[need];  // 加上这个 B 在数列中出现的次数
        }
    }

    cout << answer << endl;                 // 输出数对总数
    return 0;                               // 程序正常结束
}
```

### 逐行理解

- `count[a[i]]++`：这个数出现次数加 1。
- 若现在 `A = 10`、`C = 3`，就要找 `B = 7`。
- `count[need]` 就是问：7 出现了几次。
- `long long` 能装更大的答案，避免数字太大装不下。

`c == 0` 是特殊情况：相同的两个数可以组成一对，但同一个位置不能和自己组成一对，所以用 `howMany * (howMany - 1) / 2` 来数不同位置的两两组合。

## 5. P1149 火柴棒等式

### 思路

加号和等号一共先用掉 4 根火柴。然后直接枚举加数 `a` 和 `b`，`c` 就是 `a + b`。计算三者需要的火柴数是否刚好等于输入。

### 代码

```cpp
#include <iostream>                         // 使用 cin、cout
using namespace std;                        // 使用标准命名空间

int sticks[10] = {6, 2, 5, 5, 4, 5, 6, 3, 7, 6}; // sticks[d] 是拼数字 d 需要的火柴数

int countSticks(int x) {                    // 这个函数专门计算整数 x 需要几根火柴
    if (x == 0) {                            // 0 不能进入下面的 while，所以要单独处理
        return 6;                            // 数字 0 需要 6 根火柴
    }

    int answer = 0;                          // answer 累加 x 的每一位所需火柴数

    while (x > 0) {                          // 只要 x 还有数字，就继续检查最右边一位
        int digit = x % 10;                  // 取出最右边的数字，例如 123 的最右边是 3
        answer = answer + sticks[digit];     // 加上拼这个数字所需的火柴数
        x = x / 10;                          // 删掉最右边一位，例如 123 变成 12
    }

    return answer;                           // 把计算好的火柴总数交回去
}

int main() {                                // 程序开始
    int n;                                  // n 是题目给的火柴总数
    cin >> n;                               // 读入 n

    int answer = 0;                         // answer 记录能拼出的等式数量

    for (int a = 0; a <= 1000; a++) {      // 一个一个试第一个加数 a
        for (int b = 0; b <= 1000; b++) {  // 一个一个试第二个加数 b
            int c = a + b;                  // 等号右边的 c 不用猜，直接由 a+b 算出

            int need = countSticks(a) + countSticks(b) + countSticks(c) + 4; // + 和 = 共需要 4 根

            if (need == n) {                // 如果刚好把 n 根火柴全部用完
                answer++;                   // 找到一种等式，答案加 1
            }
        }
    }

    cout << answer << endl;                 // 输出一共有多少种等式
    return 0;                               // 程序正常结束
}
```

### 为什么 `0` 要特别处理？

`while (x > 0)` 遇到 `x = 0` 时一次也不会进入。但数字 0 明明需要 6 根火柴，所以要先单独写：

```cpp
if (x == 0) return 6;
```

## 6. P1036 选数

### 思路

从 `n` 个数中选 `k` 个，问它们的和是素数的方案有多少个。

因为 `n` 最多只有 20，所以可以一个一个试着选。这里用一个很基础的“递归选择”函数：

> 还没选够时，从后面的数字中挑一个，继续选；选够后，检查总和是不是素数。

### 代码

```cpp
#include <iostream>                         // 使用 cin、cout
using namespace std;                        // 使用标准命名空间

int n, k;                                  // n 是数字总数，k 是每次必须选几个数
int a[25];                                 // a[i] 保存第 i 个输入数字
int answer = 0;                            // answer 记录“和是素数”的选法数量

bool isPrime(int x) {                      // 这个函数检查 x 是不是素数
    if (x < 2) {                           // 0 和 1 都不是素数
        return false;                      // 告诉调用者：不是素数
    }

    for (int i = 2; i * i <= x; i++) {    // 从 2 开始试着用 i 去除 x
        if (x % i == 0) {                  // 如果余数是 0，说明 x 能被 i 整除
            return false;                  // 能整除就不是素数，马上结束检查
        }
    }

    return true;                           // 没有任何数能整除 x，所以 x 是素数
}

void choose(int start, int chosen, int sum) { // 从 start 开始选；已选 chosen 个；目前和为 sum
    if (chosen == k) {                       // 已经刚好选够 k 个数
        if (isPrime(sum)) {                  // 检查这 k 个数的和是不是素数
            answer++;                        // 是素数，这种选法就要计入答案
        }
        return;                              // 这一种选法检查完，回到上一层继续试别的数
    }

    for (int i = start; i <= n; i++) {      // 轮流选择第 i 个数作为“下一个选中的数”
        choose(i + 1, chosen + 1, sum + a[i]); // 选了它后，只能从它后面的数继续选
    }
}

int main() {                                // 程序开始
    cin >> n >> k;                          // 读入总数 n 和要选的个数 k

    for (int i = 1; i <= n; i++) {          // 读入全部 n 个数字
        cin >> a[i];                        // 保存第 i 个数字
    }

    choose(1, 0, 0);                        // 从第 1 个数开始；开始时没选数；总和为 0

    cout << answer << endl;                 // 输出答案
    return 0;                               // 程序正常结束
}
```

### `choose(1, 0, 0)` 是什么意思？

三个数字依次表示：

```text
从第 1 个数开始选；现在选了 0 个；目前总和是 0。
```

每次选择 `a[i]` 后，下一次从 `i + 1` 开始。因此不会重复选同一个数，也不会把“选 2 再选 5”和“选 5 再选 2”算成两种方案。

## 7. P2089 烤鸡

### 思路

一共有 10 种配料，每种只能放 1、2、3 克。直接按顺序给每一种配料试 1 克、2 克、3 克。

选择完第 10 种时，如果总重量刚好是 `n`，就保存这一个方案。

### 代码

```cpp
#include <iostream>                         // 使用 cin、cout
using namespace std;                        // 使用标准命名空间

int n;                                      // n 是题目要求的总克数
int now[10];                                // now[i] 是第 i 种配料当前放了几克
int answer[60000][10];                      // 保存每一种成功方案
int count = 0;                              // count 是成功方案的数量

void make(int position, int sum) {          // 现在处理第 position 种配料；已经放了 sum 克
    if (position == 10) {                   // 10 种配料都已经决定好了
        if (sum == n) {                     // 如果总克数刚好等于题目要求
            for (int i = 0; i < 10; i++) { // 把当前这 10 个选择复制到答案表中
                answer[count][i] = now[i];  // 复制第 i 种配料的克数
            }
            count++;                        // 成功方案数量加 1
        }
        return;                             // 这一条选择路线已经走到底，返回上一层
    }

    for (int gram = 1; gram <= 3; gram++) { // 第 position 种配料依次试 1 克、2 克、3 克
        now[position] = gram;               // 先记住这一次选择了 gram 克
        make(position + 1, sum + gram);     // 再去决定下一种配料，并更新总克数
    }
}

int main() {                                // 程序开始
    cin >> n;                               // 读入目标总克数

    make(0, 0);                             // 从第 0 种配料开始；开始时总克数是 0

    cout << count << endl;                  // 先输出方案总数

    for (int i = 0; i < count; i++) {       // 一行一行输出每个成功方案
        for (int j = 0; j < 10; j++) {      // 输出这一行的 10 种配料克数
            cout << answer[i][j] << ' ';    // 输出第 j 种配料的克数
        }
        cout << endl;                       // 一个方案输出完，换到下一行
    }

    return 0;                               // 程序正常结束
}
```

### 为什么输出顺序正确？

每种配料都按 `1 → 2 → 3` 的顺序尝试，前面的配料优先变化得慢，后面的配料变化得快。这刚好是题目要求的字典序。

## 8. P2670 扫雷游戏

### 思路

每一个非地雷格 `?`，都去检查周围的八个方向。看到 `*` 就计数加 1。

### 代码

```cpp
#include <iostream>                         // 使用 cin、cout
using namespace std;                        // 使用标准命名空间

int main() {                                // 程序开始
    int n, m;                               // n 是地图行数，m 是地图列数
    cin >> n >> m;                          // 读入行数和列数

    char a[105][105];                       // a[i][j] 保存第 i 行、第 j 列的字符

    for (int i = 1; i <= n; i++) {         // 一行一行读入地图
        for (int j = 1; j <= m; j++) {     // 读入这一行的每一列
            cin >> a[i][j];                // 保存当前格子的 * 或 ?
        }
    }

    for (int i = 1; i <= n; i++) {         // 一行一行准备输出答案地图
        for (int j = 1; j <= m; j++) {     // 处理当前这个格子 (i,j)
            if (a[i][j] == '*') {          // 如果当前格子本来就是地雷
                cout << '*';               // 地雷原样输出星号
            } else {                       // 否则当前格子是 ?，需要数附近有几颗雷
                int count = 0;             // count 从 0 开始，记录附近地雷数量

                for (int x = i - 1; x <= i + 1; x++) { // 检查上面一行、当前行、下面一行
                    for (int y = j - 1; y <= j + 1; y++) { // 每一行检查左、中、右三列
                        if (x >= 1 && x <= n &&            // 检查的行号必须还在地图内
                            y >= 1 && y <= m &&            // 检查的列号必须还在地图内
                            a[x][y] == '*') {              // 这个邻居格子如果是地雷
                            count++;                        // 附近地雷数量加 1
                        }
                    }
                }

                cout << count;             // 输出这个非地雷格周围的地雷数量
            }
        }

        cout << endl;                       // 当前这一行输出结束，换行
    }

    return 0;                               // 程序正常结束
}
```

### 为什么会检查到自己？

当 `x == i` 且 `y == j` 时，确实是在检查自己。但只有非地雷格才进入这段代码，而自己是 `?`，不是 `*`，所以不会多算。
