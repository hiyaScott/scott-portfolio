# 1016周末综合练习

这份讲义面向小学六年级学生，练习图案输出、数组比较、排序统计、动态规划、质数判断和二维网格模拟。每道题的代码可以独立提交，代码中的 `//` 后面是中文注释。

`dp` 可以理解成一排“最好成绩格子”：下标表示时间或容量，格子里的数表示目前能得到的最大结果。倒序更新表示每件物品只能用一次，正序更新表示同一种物品可以重复使用。

## 1. P5730 显示屏

![P5730 显示屏示意图](assets/walkthrough/P5730.webp)

题目来源：[洛谷 P5730](https://www.luogu.com.cn/problem/P5730)。详细要求以原题为准。

### 解题思路

用二维表保存 0 到 9 的五行图案。输入数字串后，按行输出，每个数字之间加一个空格。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <string> // 字符串工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    string shape[10][5]={ // 每个数字的五行图案。
        {"XXX","X.X","X.X","X.X","XXX"},{"..X","..X","..X","..X","..X"},{"XXX","..X","XXX","X..","XXX"},{"XXX","..X","XXX","..X","XXX"},{"X.X","X.X","XXX","..X","..X"},{"XXX","X..","XXX","..X","XXX"},{"XXX","X..","XXX","X.X","XXX"},{"XXX","..X","..X","..X","..X"},{"XXX","X.X","XXX","X.X","XXX"},{"XXX","X.X","XXX","..X","XXX"}
    }; // 图案表结束。
    int n; string s; cin>>n>>s; // 读入位数和数字串。
    for(int row=0;row<5;row++){ // 一行一行打印显示屏。
        for(int i=0;i<n;i++){ // 处理这一行中的每个数字。
            cout<<shape[s[i]-'0'][row]; // 取出当前数字的对应图案。
            if(i+1<n) cout<<' '; // 数字之间留一列空格。
        } // 当前行打印结束。
        cout<<'\n'; // 换到下一行。
    } // 五行打印结束。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
2
12
```

输出：

```text
..X XXX
..X ..X
..X XXX
..X X..
..X XXX
```

**容易错：**字符串下标从 0 开始；数字之间要有一列空格。

## 2. P1428 小鱼比可爱

![P1428 小鱼比可爱示意图](assets/walkthrough/P1428.webp)

题目来源：[洛谷 P1428](https://www.luogu.com.cn/problem/P1428)。详细要求以原题为准。

### 解题思路

第 i 条鱼只能看左边，所以把每一条鱼和它左边的所有鱼比较，严格更小才计数。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n,a[100]; cin>>n; // 读入鱼的数量。
    for(int i=0;i<n;i++) cin>>a[i]; // 读入每条鱼的可爱程度。
    for(int i=0;i<n;i++){ // 逐条鱼计算答案。
        int answer=0; // 当前鱼左边更不可爱的鱼数量。
        for(int j=0;j<i;j++) if(a[j]<a[i]) answer++; // 只比较左边，严格更小才算。
        cout<<answer<<' '; // 输出当前答案。
    } // 计算结束。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
4
4 3 2 3
```

输出：

```text
0 1 2 1
```

**容易错：**相同可爱程度不算“不如自己”。

## 3. P1097 统计数字

![P1097 统计数字示意图](assets/walkthrough/P1097.webp)

题目来源：[洛谷 P1097](https://www.luogu.com.cn/problem/P1097)。详细要求以原题为准。

### 解题思路

先排序。相同数字会连在一起，用两个下标找到这一段的起点和终点，终点减起点就是出现次数。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // 排序工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n; cin>>n; // 读入数字个数。
    int a[200000]; // 保存所有数字。
    for(int i=0;i<n;i++) cin>>a[i]; // 读入数字。
    sort(a,a+n); // 从小到大排序。
    for(int i=0;i<n;){ // i 指向还没有统计的第一个数字。
        int j=i; // j 向右寻找相同数字的末尾。
        while(j<n&&a[j]==a[i]) j++; // 统计这一段相同数字。
        cout<<a[i]<<' '<<j-i<<'\n'; // 输出数字和出现次数。
        i=j; // 跳过已经统计的一整段。
    } // 所有数字统计结束。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
8
2
1
2
3
1
2
3
3
```

输出：

```text
1 2
2 3
3 3
```

**容易错：**不能只输出不同数字，还要输出每个数字出现了几次。

## 4. P1616 疯狂的采药

![P1616 疯狂的采药示意图](assets/walkthrough/P1616.webp)

题目来源：[洛谷 P1616](https://www.luogu.com.cn/problem/P1616)。详细要求以原题为准。

### 解题思路

每种药可以无限采，所以这是完全背包。时间从小到大更新，表示本轮更新后还可以继续使用同一种药。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // max 工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int t,m; cin>>t>>m; // 读入总时间和药物种类数。
    int dp[10000001]={0}; // dp[x] 表示用 x 分钟最多得到的价值。
    for(int i=0;i<m;i++){ // 逐种考虑药物。
        int time,value; cin>>time>>value; // 读入采药时间和价值。
        for(int x=time;x<=t;x++) dp[x]=max(dp[x],dp[x-time]+value); // 正序更新，允许同一种药重复采摘。
    } // 所有药物处理完毕。
    cout<<dp[t]<<'\n'; // 输出最大价值。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
10 2
3 4
4 5
```

输出：

```text
13
```

**容易错：**与 P1048 不同，这里可以重复采同一种药。

## 5. P1049 装箱问题

![P1049 装箱问题示意图](assets/walkthrough/P1049.webp)

题目来源：[洛谷 P1049](https://www.luogu.com.cn/problem/P1049)。详细要求以原题为准。

### 解题思路

把物品看成只能使用一次的选择。dp[x] 保存容量不超过 x 时的最大装入体积，最后用容量减去它。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
#include <algorithm> // max 工具。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int V,n; cin>>V>>n; // 读入箱子容量和物品数量。
    int dp[201]={0}; // dp[x] 表示容量不超过 x 时装入的最大体积。
    for(int i=0;i<n;i++){ // 逐个考虑物品。
        int volume; cin>>volume; // 读入物品体积。
        for(int x=V;x>=volume;x--) dp[x]=max(dp[x],dp[x-volume]+volume); // 倒序更新，每件物品只能装一次。
    } // 所有物品处理完毕。
    cout<<V-dp[V]<<'\n'; // 箱子容量减去已装最大体积就是最小剩余空间。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
10
3
6
4
3
```

输出：

```text
0
```

**容易错：**内层容量必须倒序，否则同一件物品可能被重复装入。

## 6. P5723 质数口袋

![P5723 质数口袋示意图](assets/walkthrough/P5723.webp)

题目来源：[洛谷 P5723](https://www.luogu.com.cn/problem/P5723)。详细要求以原题为准。

### 解题思路

从 2 开始判断质数，能装下就输出并加入总和；遇到第一个装不下的质数就停止，因为后面的质数更大。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
using namespace std; // 使用标准名字。
bool prime(int x){ // 判断 x 是否为质数。
    if(x<2) return false; // 0 和 1 不是质数。
    for(int d=2;d*d<=x;d++) if(x%d==0) return false; // 找到能整除的数就不是质数。
    return true; // 没找到因数，所以是质数。
} // 判断函数结束。
int main(){ // 程序开始。
    int L; cin>>L; // 读入口袋承重量。
    int sum=0,count=0; // 保存已经装入的总和和质数个数。
    for(int x=2;;x++){ // 从 2 开始依次检查自然数。
        if(prime(x)&&sum+x<=L){ // 当前数是质数且装入后不超重。
            cout<<x<<'\n'; // 输出装入的质数。
            sum+=x; count++; // 更新总和和数量。
        }else if(prime(x)){ // 当前是质数但装入会超重。
            break; // 后面的质数更大，也不可能再装入。
        } // 当前数处理结束。
    } // 检查结束。
    cout<<count<<'\n'; // 输出质数个数。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
20
```

输出：

```text
2
3
5
7
4
```

**容易错：**示例中 2+3+5+7=17，下一质数 11 会超重，所以输出 2、3、5、7 和 4。

## 7. P1789 插火把

![P1789 插火把示意图](assets/walkthrough/P1789.webp)

题目来源：[洛谷 P1789](https://www.luogu.com.cn/problem/P1789)。详细要求以原题为准。

### 解题思路

用二维数组表示每个格子是否有光。火把按题目给出的十字图案照亮，萤石照亮周围完整的 5×5 方块，最后数没有被照亮的格子。

### 逐行注释代码

```cpp
#include <iostream> // 输入输出。
using namespace std; // 使用标准名字。
int main(){ // 程序开始。
    int n,m,k; cin>>n>>m>>k; // 读入方阵边长、火把数和萤石数。
    bool light[105][105]={false}; // light 表示这个格子是否被照亮或放置物品。
    for(int z=0;z<m;z++){ // 处理每一个火把。
        int x,y; cin>>x>>y; // 读入火把位置。
        for(int dx=-2;dx<=2;dx++) for(int dy=-2;dy<=2;dy++){ // 查看周围 5×5 范围。
            if((abs(dx)<=1&&abs(dy)<=1)||(dx==0&&abs(dy)==2)||(dy==0&&abs(dx)==2)) light[x+dx][y+dy]=true; // 按火把图案照亮。
        } // 当前火把处理完毕。
    } // 火把处理结束。
    for(int z=0;z<k;z++){ // 处理每个萤石。
        int x,y; cin>>x>>y; // 读入萤石位置。
        for(int dx=-2;dx<=2;dx++) for(int dy=-2;dy<=2;dy++) light[x+dx][y+dy]=true; // 萤石周围整块 5×5 都亮。
    } // 萤石处理结束。
    int dark=0; // 保存没有光且没有物品的格子数。
    for(int x=1;x<=n;x++) for(int y=1;y<=n;y++) if(!light[x][y]) dark++; // 逐格统计黑暗位置。
    cout<<dark<<'\n'; // 输出会生成怪物的位置数。
    return 0; // 正常结束。
} // main 结束。
```

### 自拟测试

输入：

```text
5 1 0
3 3
```

输出：

```text
0
```

**容易错：**坐标可能靠近边界，数组开大一些；只统计 1 到 n 的方阵格子。
