### 常用写法小词典

| 写法 | 意思 |
| --- | --- |
| `cin >> x` | 读入 x |
| `cout << x` | 输出 x |
| `=` / `==` | 赋值 / 判断是否相等 |
| `/` / `%` | 整数除法 / 求余数 |
| `x++` | x 加 1 |

## 1. P1425 小鱼的游泳时间

题目来源：[洛谷 P1425](https://www.luogu.com.cn/problem/P1425)。具体题目要求以原页面为准。

### 先读懂任务

输入开始的小时、分钟和结束的小时、分钟，求一共经过多少小时多少分钟。题目保证在当天结束，结束晚于开始，不需要处理跨天。

### 把时间统一成分钟

想象一把从零点开始的“分钟尺”：1 小时等于 60 分钟，所以 `小时 × 60 + 分钟` 就是时间在尺子上的位置。两个位置相减，就是经过的时间。

例如从 9:50 到 11:10：

| 要计算的量 | 算式 | 结果 |
| --- | --- | --- |
| 开始位置 | 9 × 60 + 50 | 590 分钟 |
| 结束位置 | 11 × 60 + 10 | 670 分钟 |
| 经过时间 | 670 − 590 | 80 分钟 |
| 完整小时 | 80 / 60 | 1 小时 |
| 剩余分钟 | 80 % 60 | 20 分钟 |

这里 `/` 是整数除法，`%` 是求余数。这样写不用手工借一个小时。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int a, b, c, d; // 保存开始的时、分和结束的时、分。
    cin >> a >> b >> c >> d; // 按顺序读入四个整数。
    int begin = a * 60 + b; // 把开始时间换算成从零点起的分钟数。
    int end = c * 60 + d; // 把结束时间也换算成分钟数。
    int total = end - begin; // 相减得到游泳的总分钟数。
    int hours = total / 60; // 每 60 分钟组成一个完整小时。
    int minutes = total % 60; // 剩下不足一小时的分钟数。
    cout << hours << ' ' << minutes << '\n'; // 输出小时和分钟，中间有一个空格。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
9 50 11 10
```

输出：

```text
1 20
```

再检查 `10 0 11 0`，应输出 `1 0`；`8 59 9 0`，应输出 `0 1`。

**容易错：**直接把小时和分钟分别相减，会得到负的分钟数。先统一单位就能避免这个问题。输出是两个整数，中间一个空格，不要写“小时”“分钟”。

只做几次运算，时间和额外存储都是固定的。

小练习：从 13:45 到 16:05，经过了多久？

## 2. P1179 数字统计

题目来源：[洛谷 P1179](https://www.luogu.com.cn/problem/P1179)。具体题目要求以原页面为准。

### 先读懂任务

检查 L 到 R 的所有整数，统计数字 `2` 的出现次数。注意是“有多少个 2”，不是“有多少个数包含 2”。例如 `222` 要算三次。

### 一个数一个数查，一位一位拆

外层循环负责挑出每一个整数，内层循环负责检查这个整数的每一位。

把数字当作一串积木，每次取最右边一块：`x % 10` 得到末位，`x / 10` 去掉末位。

以 `222` 为例：

| 当前 x | 取出的末位 | 去掉末位后的 x | 本轮是否加 1 |
| --- | --- | --- | --- |
| 222 | 2 | 22 | 是 |
| 22 | 2 | 2 | 是 |
| 2 | 2 | 0 | 是 |

必须复制一份 `x = number` 来拆。如果直接拆外层的 `number`，就会破坏“下一个要检查哪个整数”的记录。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int L, R; // 保存范围的左端点和右端点。
    cin >> L >> R; // 读入两个端点。
    int answer = 0; // 记录数字 2 出现的总次数。
    for (int number = L; number <= R; number++) { // 从 L 到 R，两个端点都要检查。
        int x = number; // 复制当前数字，拆副本就不会改变外层循环变量。
        while (x > 0) { // 只要还有数位没有检查，就继续。
            int digit = x % 10; // 取出最右边的一位数字。
            if (digit == 2) { // 判断这一位是否为 2。
                answer++; // 找到一个 2，总次数加 1。
            } // 当前数位的判断结束。
            x = x / 10; // 去掉已经检查的最右边一位。
        } // 当前整数的所有数位检查完毕。
    } // 范围内的所有整数检查完毕。
    cout << answer << '\n'; // 输出数字 2 的总次数。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
20 23
```

输出：

```text
5
```

因为 20、21、22、23 分别贡献 1、1、2、1 次。

再检查 `222 222`，应输出 `3`；`3 9`，应输出 `0`。

**容易错：**发现一个 2 后不能立刻停止；右端点 R 也必须检查，所以循环条件用 `number <= R`。

题目规定 R 不超过 100000。最多检查十万个整数，每个最多六位，不需要复杂算法。额外只保存几个整数。

小练习：输入 `1 25`，答案是多少？

## 3. P1147 连续正整数和

题目来源：[洛谷 P1147](https://www.luogu.com.cn/problem/P1147)。具体题目要求以原页面为准。

### 先读懂任务

找出所有这样的整数段：数字连续、全是正整数、至少两个数，而且总和等于 M。每行输出起点和终点，起点小的先输出。

例如 M = 15，有 `1+2+3+4+5`、`4+5+6`、`7+8` 三种。单独一个 `15` 不算。

### 用左右边界圈住一段数字

这道题需要一点新的想法：用一条可以伸缩的“框”圈住连续整数。`left` 是框的左边，`right` 是框的右边，`sum` 保存框内数字的和。

- 和太小：右边伸长一格，加入下一个整数。
- 和太大：左边缩进一格，减掉最左边的整数。
- 和刚好：记录答案，然后也从左边缩进一格，继续找。

不必每次重新求和。框里加一个数就加到 sum，移走一个数就从 sum 减掉。

以 M = 15 演示部分过程：

| 当前框 | 总和 | 下一步 |
| --- | --- | --- |
| [1, 2] | 3 | 加入 3 |
| [1, 3] | 6 | 加入 4 |
| [1, 4] | 10 | 加入 5 |
| [1, 5] | 15 | 输出 1 5，再移走 1 |
| [2, 5] | 14 | 加入 6 |
| [2, 6] | 20 | 移走 2 |
| [3, 6] | 18 | 移走 3 |
| [4, 6] | 15 | 输出 4 6，再移走 4 |

### 为什么不会漏答案？

所有数都为正数，所以固定左端点时，右端点越往右，总和越大。和小于 M 时，缩短右边只会更小；和大于 M 时，再增加右边只会更大。因此可以按上面的规则移动。

左端点只往右走，所以答案天然按起点从小到大输出。同一个起点最多有一个答案，因为总和会随右端点增大而严格增大。

至少两个数的段，最小也要包含 `left` 和 `left+1`。如果 `left > M/2`，这两个数的和就已经大于 M，可以停止。过程中可能暂时出现单个数的框，所以输出前仍检查 `left < right`。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int M; // 保存要求的总和。
    cin >> M; // 读入 M。
    int left = 1; // 当前连续整数段从 1 开始。
    int right = 2; // 当前连续整数段到 2 结束。
    int sum = 3; // 初始段是 1、2，它们的和为 3。
    while (left <= M / 2) { // 两个及以上正整数的起点不可能超过 M 的一半。
        if (sum < M) { // 当前的和太小，需要增加一个更大的数。
            right++; // 把右端点向右移动一格。
            sum += right; // 把新加入的数加到当前总和里。
        } else { // 当前的和等于或大于 M，都准备移走最左边的数。
            if (sum == M && left < right) { // 和正好为 M，并且至少包含两个数。
                cout << left << ' ' << right << '\n'; // 输出这一段的左右端点。
            } // 是否找到答案的判断结束。
            sum -= left; // 先从总和里减掉原来的最左边的数。
            left++; // 再把左端点向右移动一格。
        } // 本轮移动结束。
    } // 所有可能的起点检查完毕。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
15
```

输出：

```text
1 5
4 6
7 8
```

再检查 M = 10，应只输出 `1 4`；M = 21，应依次输出 `1 6`、`6 8`、`10 11`（分别占一行）。

**容易错：**左边缩进时，要先减掉旧的 left，再执行 `left++`。右边伸长时，要先执行 `right++`，再加入新的 right。

M 最多为 2000000。两端都只向右走，移动总次数随 M 成正比；不需要保存整个整数段，只用几个变量。代码中 sum 最大不会超过约 2M，`int` 足够保存。

小练习：M = 18 时有哪些答案？

## 4. P2550 彩票摇奖

题目来源：[洛谷 P2550](https://www.luogu.com.cn/problem/P2550)。具体题目要求以原页面为准。

### 先读懂任务

对每张彩票，数一数它的七个号码中有几个属于中奖号码。号码出现的位置不影响结果。最后统计各个奖项有多少张彩票。

| 命中号码个数 | 奖项 | 保存的位置 |
| --- | --- | --- |
| 7 | 特等奖 | count[7] |
| 6 | 一等奖 | count[6] |
| 5 | 二等奖 | count[5] |
| 4 | 三等奖 | count[4] |
| 3 | 四等奖 | count[3] |
| 2 | 五等奖 | count[2] |
| 1 | 六等奖 | count[1] |
| 0 | 未中奖 | count[0]，不输出 |

### 像核对名单一样比较

用数组 `win` 保存中奖名单。每读入一个彩票号码，就和名单里的七个号码逐个比较，找到相同的就让 hit 加 1。

题目保证一张彩票内的号码互不相同，中奖名单内的号码也互不相同。所以一个号码找到一次就可以停止比较，`break` 会结束最里面的那层循环。

用 `count` 当作八个计数格：`count[hit]++` 表示把当前彩票放进“恰好命中 hit 个”的那一格。一张彩票只记入一个奖项，不要把命中七个的彩票也算进一等奖。

数组下标从 0 开始：`win[7]` 声明七个格子，可用下标是 0 到 6；`count[8]` 声明八个格子，可用下标是 0 到 7。`= {0}` 会把 count 的全部格子初始化为 0。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int n; // 保存彩票张数。
    cin >> n; // 读入彩票张数。
    int win[7]; // 保存七个中奖号码，下标从 0 到 6。
    for (int i = 0; i < 7; i++) { // 依次读入七个中奖号码。
        cin >> win[i]; // 把当前号码放进数组。
    } // 中奖号码读入完毕。
    int count[8] = {0}; // count[k] 记录恰好中 k 个号码的彩票张数，全部从 0 开始。
    for (int ticket = 0; ticket < n; ticket++) { // 一张一张地处理彩票。
        int hit = 0; // 当前这张彩票暂时中了 0 个号码。
        for (int i = 0; i < 7; i++) { // 逐个检查当前彩票的七个号码。
            int number; // 保存当前读入的彩票号码。
            cin >> number; // 读入一个号码。
            for (int j = 0; j < 7; j++) { // 拿这个号码和七个中奖号码分别比较。
                if (number == win[j]) { // 如果在中奖号码中找到了它。
                    hit++; // 当前彩票的命中数加 1。
                    break; // 中奖号码互不相同，找到后不必继续比较。
                } // 是否命中的判断结束。
            } // 当前号码比较完毕。
        } // 当前彩票的七个号码检查完毕。
        count[hit]++; // 把这张彩票记入对应命中数的计数格。
    } // 所有彩票处理完毕。
    for (int k = 7; k >= 1; k--) { // 按命中 7 个到命中 1 个的顺序输出。
        if (k != 7) { // 如果不是输出的第一个数字。
            cout << ' '; // 先输出分隔用的空格。
        } // 空格处理结束。
        cout << count[k]; // 输出对应奖项的彩票张数。
    } // 七个奖项输出完毕。
    cout << '\n'; // 输出换行。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
3
1 2 3 4 5 6 7
7 6 5 4 3 2 1
1 2 8 9 10 11 12
8 9 10 11 12 13 14
```

输出：

```text
1 0 0 0 0 1 0
```

第一张全部命中，是特等奖；第二张命中两个，是五等奖；第三张未中奖，不属于输出的七个奖项。

**容易错：**每处理一张新彩票，都要重新把 hit 设为 0；输出从 count[7] 到 count[1]，不要倒过来；不是只比较同一个位置上的号码。

每张彩票最多做 7 × 7 = 49 次号码比较，n 小于 1000，最多不到 49000 次比较。只用固定大小的两个数组，无需保存所有彩票。

小练习：中奖号码为 1 到 7，一张彩票为 `1 2 3 4 8 9 10`，它属于哪个奖项？

## 练习答案

- P1425：2 小时 20 分钟，输出 `2 20`。
- P1179：9 次。2、12 各一次，20 到 25 共七次。
- P1147：输出 `3 6` 和 `5 7`，各占一行。
- P2550：命中四个号码，属于三等奖。

可以按“时间换算 → 数位拆分 → 数组计数 → 连续整数段”的顺序学习，最后再练 P1147。读代码时，试着解释每个变量保存什么，以及每一轮循环改变了什么。
