# 排序模拟测试

适合小学六年级的 C++ 学习讲义。每道题提供思路、自拟例子、逐行中文注释代码和易错提醒。每份代码都能独立提交，不能把五个 main 放进同一个程序。

## 先学会“信息卡排队”

`struct` 就像一张卡片的格式，把同一个人的信息绑在一起。`students[i].score` 表示第 i 张卡片上的分数。排序时整张卡移动，姓名、编号和分数不会散开。

`sort(数组, 数组+n, 比较函数)` 会整理前 n 张卡片。比较函数返回 true，表示第一个人应该在第二个人前面。比较规则一般用严格的 `>` 或 `<`，相等时再看下一条规则，不要用 `>=` 或 `<=`。

| 写法 | 意思 |
| --- | --- |
| `=` / `==` / `!=` | 赋值 / 判断相等 / 判断不相等 |
| `x++` | x 增加 1 |
| `&&` | 两个条件都要成立 |
| `return` | 把结果交回调用处 |
| `//` | 后面是中文解释，电脑不执行 |

建议先学前四题；P3968 作为进阶题，先手算操作，再分阶段理解代码。它不是只会 sort 就能解决的普通排序题。

## 1. P5740 最厉害的学生

![P5740 最厉害的学生示意图](assets/walkthrough/P5740.webp)

题目来源：[洛谷 P5740](https://www.luogu.com.cn/problem/P5740)。详细要求以原题为准。

### 解题思路

只需要找第一名，不必把所有人排序。像打擂台一样保存当前最高总分和完整信息；新学生总分严格更高才更新，同分保留先输入的人。best 从 -1 开始，因此全为 0 分时也能选中第一个学生。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <string> // 使用字符串保存姓名。
using namespace std; // 可以直接使用标准工具的名字。
int main() { // 程序开始。
    int n; // 学生人数。
    cin >> n; // 读入人数。
    string name, bestName; // 当前姓名和最高总分学生的姓名。
    int best = -1, bestChinese = 0, bestMath = 0, bestEnglish = 0; // 保存最好记录，-1 比所有合法总分都小。
    for (int i = 0; i < n; i++) { // 按输入顺序检查学生。
        int chinese, math, english; // 当前学生的三科成绩。
        cin >> name >> chinese >> math >> english; // 读入当前学生的信息。
        int total = chinese + math + english; // 计算总分。
        if (total > best) { // 只有严格超过记录才替换，同分保留先输入的人。
            best = total; // 保存新的最高总分。
            bestName = name; // 保存对应姓名。
            bestChinese = chinese; // 保存对应语文成绩。
            bestMath = math; // 保存对应数学成绩。
            bestEnglish = english; // 保存对应英语成绩。
        } // 当前学生判断结束。
    } // 全部学生检查结束。
    cout << bestName << ' ' << bestChinese << ' ' << bestMath << ' ' << bestEnglish << '\n'; // 输出姓名和各科成绩。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
3
ann 100 90 80
bob 90 100 80
cat 100 100 100
```

输出：

```text
cat 100 100 100
```

**易错提醒：**总分相同不能改成 >=；输出的是姓名与三科成绩，不是总分。

**运行规模：**检查 n 次，额外只保存当前学生和最好记录。

## 2. P1093 奖学金

![P1093 奖学金示意图](assets/walkthrough/P1093.webp)

题目来源：[洛谷 P1093](https://www.luogu.com.cn/problem/P1093)。详细要求以原题为准。

### 解题思路

给每个学生做一张信息卡，保存学号、语文、总分。比较时依次看总分、语文、学号：前一项相同才看后一项。学号按输入顺序从 1 开始，不是另外输入的。sort 排好后，输出前五张卡。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <algorithm> // 使用排序工具。
using namespace std; // 可以直接使用标准工具的名字。
struct Student { // 定义学生信息卡。
    int id, chinese, total; // 保存学号、语文分数和总分。
}; // 信息卡定义结束。
bool better(Student a, Student b) { // 判断 a 是否应排在 b 前面。
    if (a.total != b.total) { // 总分不同就先比较总分。
        return a.total > b.total; // 总分高的在前。
    } // 总分比较结束。
    if (a.chinese != b.chinese) { // 总分相同时比较语文。
        return a.chinese > b.chinese; // 语文分数高的在前。
    } // 语文比较结束。
    return a.id < b.id; // 前两项相同时，学号小的在前。
} // 排序规则结束。
int main() { // 程序开始。
    int n; // 学生人数。
    cin >> n; // 读入人数。
    Student students[300]; // 保存最多 300 张信息卡。
    for (int i = 0; i < n; i++) { // 逐个读入成绩。
        int chinese, math, english; // 当前三科成绩。
        cin >> chinese >> math >> english; // 读入三科成绩。
        students[i].id = i + 1; // 学号从 1 开始，数组下标从 0 开始。
        students[i].chinese = chinese; // 保存语文分数以便同分比较。
        students[i].total = chinese + math + english; // 保存总分。
    } // 输入结束。
    sort(students, students + n, better); // 按三条规则排好前 n 张卡片。
    for (int i = 0; i < 5; i++) { // 只输出前五名。
        cout << students[i].id << ' ' << students[i].total << '\n'; // 输出学号和总分。
    } // 输出结束。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
6
90 80 80
80 90 80
90 80 80
100 90 90
70 80 80
100 100 100
```

输出：

```text
6 300
4 280
1 250
3 250
2 250
```

**易错提醒：**总分相同还要比较语文；学号只在前两项都相同时起作用。只输出五行，每行学号与总分。

**运行规模：**排序大约需要 n×log₂n 次比较，n 最大 300；保存 n 张信息卡。

## 3. P1068 分数线划定

![P1068 分数线划定示意图](assets/walkthrough/P1068.webp)

题目来源：[洛谷 P1068](https://www.luogu.com.cn/problem/P1068)。详细要求以原题为准。

### 解题思路

先按分数降序、报名号升序排队。计划录取 m 人，用第 m*3/2 名的分数划线，整数除法会舍去小数。名次从 1 开始，数组下标从 0 开始，因此查 rank-1。再统计所有不低于分数线的人，包括同分的人。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
#include <algorithm> // 使用 C++ 提供的 sort 排序工具。
using namespace std; // 可以直接写 cin、cout 和 sort。
struct Student { // 定义一张选手信息卡，把报名号和分数放在一起。
    int id; // 这张卡片上的报名号。
    int score; // 这张卡片上的笔试分数。
}; // 信息卡的定义结束，注意这里有分号。
bool better(Student a, Student b) { // 告诉排序工具：a 是否应该排在 b 前面。
    if (a.score != b.score) { // 如果两人的分数不同。
        return a.score > b.score; // 分数高的人排在前面。
    } // 分数不同的处理结束。
    return a.id < b.id; // 分数相同时，报名号小的人排在前面。
} // 排序规则函数结束。
int main() { // 程序从这里开始。
    int n, m; // 保存报名人数和计划录取人数。
    cin >> n >> m; // 读入两个人数。
    Student students[5000]; // 准备最多 5000 张选手信息卡。
    for (int i = 0; i < n; i++) { // 逐个读入选手的信息。
        cin >> students[i].id >> students[i].score; // 把报名号和分数写到同一张卡片上。
    } // 所有选手信息读入完毕。
    sort(students, students + n, better); // 按 better 规则，把前 n 张卡片排好队。
    int rank = m * 3 / 2; // 计算 m 的 150%，整数除法自动向下取整。
    int line = students[rank - 1].score; // 第 rank 名对应下标 rank-1，它的分数就是分数线。
    int total = 0; // 暂时还没有统计进入面试的人数。
    while (total < n && students[total].score >= line) { // 从队首开始，统计所有达到分数线的人。
        total++; // 当前选手达到分数线，人数加 1。
    } // 面试人数统计完毕。
    cout << line << ' ' << total << '\n'; // 先输出分数线和实际面试人数。
    for (int i = 0; i < total; i++) { // 按排好的顺序输出进入面试的选手。
        cout << students[i].id << ' ' << students[i].score << '\n'; // 输出这名选手的报名号和分数。
    } // 进入面试的选手输出完毕。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自拟测试

输入：

```text
6 3
1006 80
1002 90
1005 85
1004 85
1001 95
1003 85
```

输出：

```text
85 5
1001 95
1002 90
1003 85
1004 85
1005 85
```

**易错提醒：**第 4 名的分数为 85，第 5 名也是 85，所以实际面试人数为 5。不能只输出规定名次以内的人。

**运行规模：**排序大约需要 n×log₂n 次比较，n 最大 5000；之后顺序扫描，保存 n 张信息卡。

## 4. P1786 帮贡排序

![P1786 帮贡排序示意图](assets/walkthrough/P1786.webp)

题目来源：[洛谷 P1786](https://www.luogu.com.cn/problem/P1786)。详细要求以原题为准。

### 解题思路

分成两次排队。第一次决定新职位：帮主和两名副帮主固定，其余按帮贡降序、原输入顺序升序排列，然后按名次分配职位。第二次决定最终显示顺序：新职位从高到低，同职位等级从高到低，再同分时按原输入顺序。原输入顺序必须永久保存，不能用第一次排序后的下标代替。

职位编号从 0 到 6，依次为帮主、副帮主、护法、长老、堂主、精英、帮众。编号越小，职位越高。

| 可调整人员的名次 | 新职位 |
| --- | --- |
| 1～2 | 护法 |
| 3～6 | 长老 |
| 7～13 | 堂主 |
| 14～38 | 精英 |
| 39 及以后 | 帮众 |

不要求帮主和副帮主在输入中位于前三行，代码会按身份把他们放在前面。题目保证恰有一名帮主和两名副帮主。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <string> // 使用姓名和职位字符串。
#include <algorithm> // 使用排序工具。
using namespace std; // 可以直接使用标准工具的名字。
string jobs[7] = {"BangZhu", "FuBangZhu", "HuFa", "ZhangLao", "TangZhu", "JingYing", "BangZhong"}; // 职位编号越小越高。
struct Member { // 定义帮友信息卡。
    string name; // 帮友姓名。
    int job, contribution, level, order; // 职位编号、帮贡、等级、原输入顺序。
}; // 信息卡定义结束。
bool byContribution(Member a, Member b) { // 第一次排序决定新职位。
    bool fixedA = a.job <= 1; // 帮主和副帮主的职位不能调整。
    bool fixedB = b.job <= 1; // 判断 b 是否也属于固定职位。
    if (fixedA != fixedB) { // 一人固定、一人可调整时。
        return fixedA; // 固定职位的人排在前面。
    } // 固定身份比较结束。
    if (fixedA) { // 两人都是固定职位时。
        return a.order < b.order; // 暂时按原输入顺序排列。
    } // 固定人员比较结束。
    if (a.contribution != b.contribution) { // 可调整人员先比较帮贡。
        return a.contribution > b.contribution; // 帮贡高的在前。
    } // 帮贡比较结束。
    return a.order < b.order; // 帮贡相同时，原先输入的在前。
} // 第一次排序规则结束。
bool byDisplay(Member a, Member b) { // 第二次排序决定显示顺序。
    if (a.job != b.job) { // 职位不同先比较职位。
        return a.job < b.job; // 职位编号小的在前。
    } // 职位比较结束。
    if (a.level != b.level) { // 职位相同时比较等级。
        return a.level > b.level; // 等级高的在前。
    } // 等级比较结束。
    return a.order < b.order; // 职位和等级都相同时，原先输入的在前。
} // 显示规则结束。
int main() { // 程序开始。
    int n; // 帮友人数。
    cin >> n; // 读入人数。
    Member members[110]; // 保存最多 110 名帮友。
    for (int i = 0; i < n; i++) { // 逐个读入帮友。
        string jobName; // 保存输入中的职位名称。
        cin >> members[i].name >> jobName >> members[i].contribution >> members[i].level; // 读入四项信息。
        members[i].order = i; // 永久保存原输入顺序，排序后也不改变。
        for (int j = 0; j < 7; j++) { // 在职位表里寻找名称。
            if (jobs[j] == jobName) { // 找到了对应职位。
                members[i].job = j; // 保存职位编号。
            } // 职位名称比较结束。
        } // 职位转换结束。
    } // 输入结束。
    sort(members, members + n, byContribution); // 固定三人排前面，其余按帮贡排队。
    for (int i = 3; i < n; i++) { // 跳过一名帮主和两名副帮主。
        int rank = i - 2; // 可调整人员的名次从 1 开始。
        if (rank <= 2) { // 前两名成为护法。
            members[i].job = 2; // 职位编号 2 是护法。
        } else if (rank <= 6) { // 第 3 到 6 名成为长老。
            members[i].job = 3; // 职位编号 3 是长老。
        } else if (rank <= 13) { // 第 7 到 13 名成为堂主。
            members[i].job = 4; // 职位编号 4 是堂主。
        } else if (rank <= 38) { // 第 14 到 38 名成为精英。
            members[i].job = 5; // 职位编号 5 是精英。
        } else { // 其余人成为帮众。
            members[i].job = 6; // 职位编号 6 是帮众。
        } // 当前人的新职位确定完毕。
    } // 职位调整结束。
    sort(members, members + n, byDisplay); // 按新职位、等级、原顺序重新排序所有人。
    for (int i = 0; i < n; i++) { // 逐个输出最终名单。
        cout << members[i].name << ' ' << jobs[members[i].job] << ' ' << members[i].level << '\n'; // 输出姓名、新职位和等级。
    } // 输出结束。
    return 0; // 正常结束。
} // 主函数结束。
```

### 自拟测试

输入：

```text
6
chief BangZhu 0 50
absi2011 FuBangZhu 0 40
deputy FuBangZhu 0 60
alice BangZhong 100 30
bob ZhangLao 100 50
carol HuFa 50 100
```

输出：

```text

deputy FuBangZhu 60
absi2011 FuBangZhu 40
```

**易错提醒：**alice 与 bob 帮贡相同，第一次 alice 在前，两人都成为护法。最终 bob 等级较高，显示在 alice 前面。副帮主的职位固定，但显示顺序仍要比较等级。

**运行规模：**排序两次，每次大约 n×log₂n 次比较；最多 110 人，保存 n 张信息卡。

## 5. P3968 电源插排

![P3968 电源插排示意图](assets/walkthrough/P3968.webp)

题目来源：[洛谷 P3968](https://www.luogu.com.cn/problem/P3968)。详细要求以原题为准。

### 解题思路

先读懂规则：到来时挑最长空段，同长选最靠右，偶数长度选右中点；同一学生编号到来、离开交替出现。查询区间内当前已用数量。完整数据最多十亿个位置、十万条操作，不能开十亿个数组格子，也不能每次逐个扫描插排。本题是五题中明显更难的一题，需要在基础排序之后学习集合、位置压缩和树状数组。

### 第一阶段：只记录连续空段

空段 [l,r] 的长度是 r-l+1，中点写成 `l + 长度/2`。例如 [1,8] 的右中点是 5。

用 set 保存“长度、左端点”二元组，它按第一项升序、第一项相同再按第二项升序自动排好。因此取最后一项，正好就是最长且最靠右的空段。一个学生到来，把空段拆成左右两段；离开时把左右空段与释放位置合起来。空段长度为 0 时不保存。

另一个 set 保存当前已用位置，用它寻找离开位置左右最近的邻居。0 和 n+1 是两名“守边界的哨兵”，不计入真实使用数量，但能保证左右邻居总是存在。

map 是对应表，像“学生编号 → 插排位置”的登记簿。表里有这个学生表示在场，这次出现就离开；表里没有表示这次到来。auto 让电脑自动写出变量类型；it 是指向集合某一项的“书签”。`it->first` 和 `it->second` 读取二元组的两项；`*it` 读取书签所指的值。

### 第二阶段：给实际位置重新编号

题目允许读完所有操作再统一输出。查询不会影响以后如何分配插排，所以第一遍先安排所有插入和拔出的位置，并按顺序保存事件；第二遍从全空状态重放事件，遇到查询才输出。

只收集实际被插入过的位置。比如十亿个插排里只用过 3、5、6，就重新编号为 1、2、3。即使一个位置第一遍结束时已经被释放，也要保留在位置表中，才能重放早先的操作。这叫位置压缩：顺序保持不变，未用过的位置不需要存储。

`lower_bound(..., l)` 找第一个不小于 l 的位置，它前面的个数就是“小于 l 的位置数”；`upper_bound(..., r)` 找第一个大于 r 的位置，它前面的个数就是“不超过 r 的位置数”。查询端点不必真的出现在位置表里。

### 第三阶段：快速数一段中的使用数量

设 prefix(t) 表示压缩后前 t 个位置的已用数。插入在对应位置加 1，拔出减 1；区间答案等于“右端点以内已用数 − 左端点之前已用数”。未来才会使用的位置，重放到它插入之前时数量一直为 0，不会提前算进答案。

树状数组是一种把计数按固定分组保存的工具。下标 i 的格子负责长度为 lowbit(i) 的一段，lowbit(i) 写作 `i & (-i)`。例如 i=6 时 lowbit 是 2，tree[6] 管第 5～6 个位置；tree[4] 管第 1～4 个位置。因此统计前 6 个位置时，先加 tree[6]，再跳到 4 加 tree[4]，两段不重复，恰好覆盖 1～6。

更新某个位置时，沿 `i += lowbit(i)` 修改所有包含它的计数格；查询前缀时沿 `i -= lowbit(i)` 拼出互不重叠的范围。每次只需大约 log₂q 步。`&` 是按位与，这一部分属于进阶内容，建议先记住“向上更新、向前累计”的用途，再学习二进制推导；不能把它理解成普通数组直接求和。

`vector` 是可以变长的数组，push_back 在末尾添一项；set 的 insert/erase 是加入/删除；map 的 find 是查找。unique 把重复位置移到末尾，再 erase 去掉它们。`for (Operation op : operations)` 就是依次取出每张操作卡。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入输出。
#include <vector> // 使用长度可以变化的数组。
#include <set> // 使用能自动保持顺序的集合。
#include <map> // 使用学生编号到位置的对应表。
#include <algorithm> // 使用排序和查找工具。
using namespace std; // 可以直接使用标准工具的名字。
struct Operation { // 保存一条操作，第二遍再统计答案。
    int type, position, left, right; // 类型：1 插入、-1 拔出、0 查询；另存位置和查询端点。
}; // 操作卡定义结束。
vector<int> tree; // 树状数组，保存压缩后的插排使用数量。
void add(int index, int value) { // 把某个位置的数量增加 value。
    while (index < (int)tree.size()) { // 沿着负责更大范围的计数格向上更新。
        tree[index] += value; // 更新当前计数格。
        index += index & (-index); // 跳到下一个需要更新的计数格。
    } // 更新结束。
} // 更新函数结束。
int prefix(int index) { // 计算前 index 个压缩位置的使用数量。
    int answer = 0; // 累加结果从 0 开始。
    while (index > 0) { // 还有未统计的范围时继续。
        answer += tree[index]; // 加上当前计数格负责的范围。
        index -= index & (-index); // 跳到前一段尚未统计的范围。
    } // 累加结束。
    return answer; // 返回前缀数量。
} // 前缀查询函数结束。
int main() { // 程序开始。
    int n, q; // 插排数量和操作数量。
    cin >> n >> q; // 读入两个数量。
    set<pair<int, int>> gaps; // 用“长度、左端点”记录每一个非空的连续空段。
    gaps.insert({n, 1}); // 最初整个 1 到 n 都为空。
    set<int> occupied; // 按位置顺序保存当前已使用的插排。
    occupied.insert(0); // 加入左边界哨兵，不是真实插排。
    occupied.insert(n + 1); // 加入右边界哨兵，不是真实插排。
    map<int, int> location; // 保存当前在场学生的插排位置。
    vector<Operation> operations; // 按时间顺序保存全部操作。
    vector<int> positions; // 收集曾经实际使用过的位置，供之后压缩。
    for (int t = 0; t < q; t++) { // 第一遍：安排插排位置，不回答查询。
        int k; // 操作开头的学生编号或 0。
        cin >> k; // 读入操作开头。
        if (k == 0) { // 0 表示区间查询。
            int l, r; // 查询端点。
            cin >> l >> r; // 读入查询区间。
            operations.push_back({0, 0, l, r}); // 保存查询，留到第二遍回答。
        } else if (location.find(k) == location.end()) { // 对应表中没有学生 k，说明这次到来。
            auto it = gaps.end(); // 先取得空段集合的末尾位置。
            --it; // 最后一项长度最大，同长度时左端点最大，也就是最靠右。
            int length = it->first; // 取出空段长度。
            int l = it->second; // 取出空段左端点。
            int r = l + length - 1; // 根据长度算出右端点。
            gaps.erase(it); // 原空段将被拆开，先删除它。
            int pos = l + length / 2; // 取中间位置，偶数长度时自动选择靠右的中点。
            if (pos > l) { // 如果中点左侧还有空位。
                gaps.insert({pos - l, l}); // 保存新的左空段。
            } // 左空段处理结束。
            if (pos < r) { // 如果中点右侧还有空位。
                gaps.insert({r - pos, pos + 1}); // 保存新的右空段。
            } // 右空段处理结束。
            occupied.insert(pos); // 记住这个位置已被使用。
            location[k] = pos; // 记住学生 k 使用的位置。
            positions.push_back(pos); // 收集实际出现的位置。
            operations.push_back({1, pos, 0, 0}); // 保存这次插入事件。
        } else { // 学生 k 当前在场，说明这次离开。
            int pos = location[k]; // 找到该学生使用的位置。
            auto it = occupied.find(pos); // 找到此位置在已用位置集合中的位置。
            auto before = it; // 准备寻找左侧最近的已用位置。
            --before; // 哨兵保证一定能找到左邻居。
            auto after = it; // 准备寻找右侧最近的已用位置。
            ++after; // 哨兵保证一定能找到右邻居。
            int a = *before, b = *after; // 左右邻居的位置，可能是边界哨兵。
            if (pos - a > 1) { // 如果原来左边存在空段。
                gaps.erase({pos - a - 1, a + 1}); // 删除原左空段。
            } // 左空段删除结束。
            if (b - pos > 1) { // 如果原来右边存在空段。
                gaps.erase({b - pos - 1, pos + 1}); // 删除原右空段。
            } // 右空段删除结束。
            gaps.insert({b - a - 1, a + 1}); // 把左空段、释放的位置、右空段合成一个新空段。
            occupied.erase(it); // 删除已使用的位置。
            location.erase(k); // 学生不再在场，下次出现会再次到来。
            operations.push_back({-1, pos, 0, 0}); // 保存这次拔出事件。
        } // 当前操作安排结束。
    } // 第一遍结束。
    sort(positions.begin(), positions.end()); // 把实际出现过的位置从小到大排列。
    positions.erase(unique(positions.begin(), positions.end()), positions.end()); // 删除重复位置。
    tree.assign(positions.size() + 1, 0); // 创建全为 0 的树状数组，下标从 1 使用。
    for (Operation op : operations) { // 第二遍：按原时间顺序重放事件并回答查询。
        if (op.type == 0) { // 当前事件是查询。
            int beforeLeft = lower_bound(positions.begin(), positions.end(), op.left) - positions.begin(); // 数出有多少个压缩位置小于左端点。
            int throughRight = upper_bound(positions.begin(), positions.end(), op.right) - positions.begin(); // 数出有多少个压缩位置不超过右端点。
            cout << prefix(throughRight) - prefix(beforeLeft) << '\n'; // 右端点以内数量减去左端点之前数量。
        } else { // 当前事件是插入或拔出。
            int index = lower_bound(positions.begin(), positions.end(), op.position) - positions.begin() + 1; // 找到实际位置对应的树状数组下标。
            add(index, op.type); // 插入加 1，拔出减 1。
        } // 当前事件统计结束。
    } // 第二遍结束。
    return 0; // 正常结束。
} // 主函数结束。
```

**易错提醒：**初次 1 号选 5，2 号选 3；1 号离开后，3 号选空段 [4,8] 的中点 6；2 号再离开，最后只占用 6。查询 0 不代表学生。

**运行规模：**所有集合维护、排序与树状数组操作合计约 q×log₂q，存储随 q 增长，不随 n 增长。
