# 四道模拟题：给六年级同学的逐行讲解（C++）

这四题看起来故事很长，但共同点都是：**按照题目写好的规则，一步一步地模拟**。这类题不需要猜答案；像玩桌游一样，每次照规则做下一步即可。

建议先读每题的“思路”，再读代码。代码里的每一行后面都有中文注释。

## 1. P1563 玩具谜题

![P1563 玩具谜题示意图](assets/walkthrough/P1563.webp)

### 题目在做什么？

有 `n` 个小人围成一个圈，每个人有朝向（朝里或朝外）和名字。开始站在第 0 个小人处。之后有 `m` 条指令，每条指令会让你向左或向右数若干个人，最后问你停在哪个小人的名字。

最容易绕的地方是：题目的“左/右”是**相对于当前小人脸朝的方向**说的。小人朝里和朝外时，左右会反过来。

### 核心思路

把小人依次存进数组 `name[0...n-1]`。用 `pos` 记录当前站在哪个位置。

对于一条指令：

- 若“指令方向”和“当前小人朝向”相同，就在数组下标上向左走，即 `pos - step`；
- 若不同，就向右走，即 `pos + step`。

圆圈走过头怎么办？用 `% n`（取余数）把位置绕回去。C++ 中负数取余可能还是负数，所以写成 `(pos % n + n) % n` 最安全。

### 示例代码（逐行注释）

```cpp
#include <bits/stdc++.h>          // 引入常用的 C++ 工具
using namespace std;              // 后面可以直接写 string、cin，不必写 std::

int main() {
    int n, m;                     // n 是小人数量，m 是指令数量
    cin >> n >> m;                // 读入 n 和 m

    vector<int> face(n);          // face[i]：第 i 个小人的朝向，0 朝里，1 朝外
    vector<string> name(n);       // name[i]：第 i 个小人的名字

    for (int i = 0; i < n; i++) { // 一个一个读入所有小人
        cin >> face[i] >> name[i]; // 读入朝向和名字，放到第 i 格
    }

    int pos = 0;                  // 一开始站在编号 0 的小人这里

    for (int i = 0; i < m; i++) { // 处理 m 条指令
        int order, step;          // order 是指令方向，step 是走几步
        cin >> order >> step;     // 读入这一条指令

        if (order == face[pos]) { // 指令方向与当前小人的朝向相同
            pos = pos - step;     // 在数组中向左移动 step 格
        } else {                  // 两个方向不相同
            pos = pos + step;     // 在数组中向右移动 step 格
        }

        pos = (pos % n + n) % n;  // 把位置绕回 0 到 n-1，负数也能正确处理
    }

    cout << name[pos] << '\n';   // 输出最后站到的小人的名字
    return 0;                     // 告诉电脑：程序正常结束
}
```

### 为什么判断是 `order == face[pos]`？

可以把它记成一个小口诀：**同号往左，不同往右。**

题目中用 0、1 表示的两个方向，刚好使得“指令方向和朝向相同”时，最后都对应数组下标往小的方向走；不同则往大的方向走。你不需要每次在脑中转圈，只要记住这个规律。

### 复杂度

读入 `n` 个小人、处理 `m` 条指令，所以时间是 `O(n + m)`；数组存了 `n` 个小人，空间是 `O(n)`。

## 2. P7072 直播获奖

![P7072 直播获奖示意图](assets/walkthrough/P7072.webp)

### 题目在做什么？

比赛分数会一个一个公布。每公布一个人，就要立刻算出“获奖分数线”：目前参加的人中，至少前 `w%` 的人获奖，而分数线至少是 1。

例如目前有 10 人、`w = 30`，就至少让前 `10 × 30% = 3` 人获奖。因此第 3 高的分数就是分数线。

### 核心思路：分数桶

题目中的分数在 `0` 到 `600`。范围很小，只有 601 种可能，所以不用每次都把一大串分数重新排序。

准备 `cnt[601]`：

- `cnt[100] = 4` 表示目前有 4 人得了 100 分；
- 每来一个新分数，就给对应格子加 1；
- 从 600 分往下数，累计人数；
- 累计到获奖人数时，现在查看的分数就是分数线。

### 示例代码（逐行注释）

```cpp
#include <bits/stdc++.h>             // 引入常用工具
using namespace std;                 // 使用标准命名空间

int main() {
    int n, w;                        // n 是总人数，w 是获奖百分比
    cin >> n >> w;                   // 读入 n 和 w

    int cnt[601] = {};               // 分数 0~600 的计数表；={} 会先全部变成 0

    for (int i = 1; i <= n; i++) {   // 第 i 次公布分数，i 从 1 开始很方便
        int score;                   // 用来存这次公布的分数
        cin >> score;                // 读入分数
        cnt[score]++;                // 这个分数出现的人数加 1

        int winners = max(1, i * w / 100); // 至少获奖人数；最少也必须是 1
        int total = 0;               // total 表示已经数到多少个高分同学

        for (int s = 600; s >= 0; s--) { // 从最高分 600 分向下找
            total += cnt[s];         // 把得到 s 分的人都算进去

            if (total >= winners) {  // 高分同学数量已经足够获奖了
                cout << s << ' ';    // s 就是当前的获奖分数线，马上输出
                break;               // 这一轮找完了，停止继续向下找
            }
        }
    }

    return 0;                        // 程序正常结束
}
```

### 一个很重要的小细节

`i * w / 100` 在 C++ 中是整数除法，小数部分会直接去掉，正好等于题目要求的向下取整。例如 `7 * 30 / 100 = 2`，表示目前至少 2 人获奖。

### 复杂度

每次公布分数，最多从 600 数到 0，也就是 601 次。这是固定的小数目，因此总时间约为 `O(601n)`，可以看作 `O(n)`；空间是 `O(601)`，也可以看作 `O(1)`。

## 3. P1518 两只塔姆沃斯牛

![P1518 两只塔姆沃斯牛示意图](assets/walkthrough/P1518.webp)

### 题目在做什么？

10×10 的地图上有农夫 `F` 和牛 `C`，还有障碍物 `*`。两个人每分钟同时行动：如果前面不是障碍物也没出界，就向前走一格；否则原地顺时针转 90 度。问他们多少分钟后会站到同一格；如果永远不会相遇，输出 0。

### 方法 1：老老实实模拟（按分钟推进）

我们要记住每个角色的：

- 行坐标 `x`；
- 列坐标 `y`；
- 面朝的方向 `d`。

方向可以编号：0 上、1 右、2 下、3 左。这样“顺时针转 90 度”就是 `(d + 1) % 4`。

为什么最多模拟 160000 分钟？每个角色有 `10 × 10 × 4 = 400` 种状态（位置 100 种，方向 4 种），两人合在一起最多 `400 × 400 = 160000` 种组合状态。如果超过这么多分钟还没相遇，某个组合状态一定重复了；之后会不断重复原来的动作，永远也不会相遇。

### 方法 1 代码（逐行注释）

```cpp
#include <bits/stdc++.h>              // 引入常用工具
using namespace std;                  // 使用标准命名空间

char grid[10][10];                    // 地图：'.' 是空地，'*' 是障碍物
int dx[4] = {-1, 0, 1, 0};            // 上、右、下、左时，行坐标的变化
int dy[4] = {0, 1, 0, -1};            // 上、右、下、左时，列坐标的变化

struct Person {                       // 做一个“小盒子”，装一个角色的状态
    int x, y, d;                       // x 行，y 列，d 是方向编号
};

bool canGo(int x, int y) {            // 判断坐标 (x,y) 能不能走进去
    return x >= 0 && x < 10 &&        // 行不能小于 0，也不能到 10 或更大
           y >= 0 && y < 10 &&        // 列不能小于 0，也不能到 10 或更大
           grid[x][y] != '*';         // 这个位置还不能是障碍物
}

void moveOne(Person &p) {             // 让角色 p 按规则行动一次；& 表示直接修改 p 本人
    int nx = p.x + dx[p.d];           // 算出正前方那一格的行
    int ny = p.y + dy[p.d];           // 算出正前方那一格的列

    if (canGo(nx, ny)) {              // 如果前方能走
        p.x = nx;                     // 就走过去，更新行坐标
        p.y = ny;                     // 更新列坐标
    } else {                          // 如果撞墙、撞障碍物或会走出地图
        p.d = (p.d + 1) % 4;          // 原地顺时针转向：上→右→下→左→上
    }
}

int main() {
    Person farmer, cow;               // 分别保存农夫和牛的状态

    for (int i = 0; i < 10; i++) {    // 读入 10 行地图
        for (int j = 0; j < 10; j++) { // 每行读入 10 个字符
            cin >> grid[i][j];        // 读入地图的一个格子

            if (grid[i][j] == 'F') {  // 找到农夫
                farmer = {i, j, 0};   // 记录位置；题目规定一开始朝上（0）
                grid[i][j] = '.';    // 把 F 当成空地，之后可以正常走到这里
            }
            if (grid[i][j] == 'C') {  // 找到牛
                cow = {i, j, 0};      // 记录牛的位置，开始也朝上
                grid[i][j] = '.';    // 同样把 C 改成空地
            }
        }
    }

    for (int minute = 0; minute <= 160000; minute++) { // 最多尝试这么多分钟
        if (farmer.x == cow.x && farmer.y == cow.y) {   // 两人是否在同一格？
            cout << minute << '\n';                    // 是：输出经过的分钟数
            return 0;                                   // 已经得到答案，结束程序
        }

        moveOne(farmer);               // 这一分钟农夫行动（两人互不阻挡，先后写无影响）
        moveOne(cow);                  // 这一分钟牛行动
    }

    cout << 0 << '\n';                // 超过所有可能状态仍未相遇，说明永远不会相遇
    return 0;                          // 程序正常结束
}
```

### 为什么可以先移动农夫，再移动牛？

题目说两人同时走，但他们不会把对方当成障碍物。每个人只看地图里的 `*`、边界和自己的朝向，不看另一个人的新位置。因此先算谁都一样；两人都走完后，再到下一轮开头检查是否相遇。

### 方法 2：方向数组写法（同思路的另一种代码）

这份写法和上面思路完全一样——每分钟都是"先看正前方，能走就前进一格，不能走就原地向右转，两人都行动后检查是否同格"。区别只在代码组织，用两个技巧让程序更短：

1. **方向数组** `dx[]`、`dy[]`：用编号 0~3 表示上右下左，查表就知道正前方是哪一格，不用写 4 个 if。
2. **状态总数判断终点**：两人状态组合最多 160000 种，超过这个数还没相遇，必然在重复旧路，直接输出 0。

> **给孩子的小口诀**：先算前方，能走就走；不能就转；走完再看有没有见面。这也是很多"地图模拟题"的通用做法。

### 方法 2 代码（逐行注释）

```cpp
#include <iostream>              // 让我们可以使用 cin 和 cout
using namespace std;             // 后面就不用反复写 std::

char a[12][12];                  // 地图。我们只使用第 1~10 行、第 1~10 列。
                                 // 开 12×12 是为了让下标 1~10 用起来更自然。

// 方向编号：0 上，1 右，2 下，3 左。
// dx 表示"行号要改变多少"。往上走，行号减 1；往下走，行号加 1。
int dx[4] = {-1, 0, 1, 0};

// dy 表示"列号要改变多少"。往右走，列号加 1；往左走，列号减 1。
int dy[4] = {0, 1, 0, -1};

int main() {
    int cx, cy, fx, fy;          // cx、cy 是牛 C 的行和列；fx、fy 是农夫 F 的行和列。
    int dc = 0, df = 0;          // dc、df 是两人的方向。
                                 // 一开始都是 0，所以都朝上。

    // 读入 10×10 的地图，同时寻找 C 和 F 在哪里。
    for (int i = 1; i <= 10; i++) {
        for (int j = 1; j <= 10; j++) {
            cin >> a[i][j];      // 读入第 i 行、第 j 列的一个格子。

            if (a[i][j] == 'C') { // 如果这里是牛 C
                cx = i;            // 记住牛的行号
                cy = j;            // 记住牛的列号
            }

            if (a[i][j] == 'F') { // 如果这里是农夫 F
                fx = i;            // 记住农夫的行号
                fy = j;            // 记住农夫的列号
            }
        }
    }

    int time = 0;                // time 记录已经过去了几分钟。

    while (true) {               // 不断模拟下一分钟，直到相遇或确定永远遇不到。

        // ===== 第 1 部分：牛先计算"正前方是哪一格" =====
        int nx = cx + dx[dc];    // nx 是牛前方格子的行号。
        int ny = cy + dy[dc];    // ny 是牛前方格子的列号。

        // 这四个条件都满足，牛才可以前进：
        // 1. nx 在地图第 1~10 行内；2. ny 在地图第 1~10 列内；3. 前方不是障碍物 *。
        if (nx >= 1 && nx <= 10 && ny >= 1 && ny <= 10 && a[nx][ny] != '*') {
            cx = nx;             // 前方能走，牛真的走到 nx、ny。
            cy = ny;
        } else {
            dc = (dc + 1) % 4;   // 前方不能走，牛原地顺时针转 90 度。
                                 // 例如：上(0)→右(1)→下(2)→左(3)→上(0)。
                                 // % 4 的作用是让 4 回到 0，方向不会跑出 0~3。
        }

        // ===== 第 2 部分：农夫也做完全一样的事情 =====
        int nfx = fx + dx[df];   // 农夫正前方的行号。
        int nfy = fy + dy[df];   // 农夫正前方的列号。

        if (nfx >= 1 && nfx <= 10 && nfy >= 1 && nfy <= 10 && a[nfx][nfy] != '*') {
            fx = nfx;            // 能走，就走一格。
            fy = nfy;
        } else {
            df = (df + 1) % 4;   // 不能走，也向右转 90 度。
        }

        time++;                  // 牛和农夫都行动完，时间才过去 1 分钟。

        // ===== 第 3 部分：这一分钟结束后，检查有没有相遇 =====
        if (cx == fx && cy == fy) { // 行相同、列也相同，就是同一格。
            cout << time << endl;   // 输出相遇时经过的分钟数。
            return 0;               // 已经找到答案，程序结束。
        }

        // ===== 第 4 部分：太久还没相遇，说明会一直重复 =====
        if (time > 160000) {
            cout << 0 << endl;      // 按题目要求，永远遇不到就输出 0。
            return 0;
        }
    }
}
```

### 方法 2 逐行讲解

代码里的注释已经很完整，这里单独讲三个重点。

**重点 1：方向数组到底是什么？**

把地图想成方格纸：`x` 是第几行，`y` 是第几列。

| 方向编号 `d` | 含义 | `dx[d]` | `dy[d]` | 走完后 |
| --- | --- | ---: | ---: | --- |
| 0 | 上 | -1 | 0 | 行号减 1 |
| 1 | 右 | 0 | 1 | 列号加 1 |
| 2 | 下 | 1 | 0 | 行号加 1 |
| 3 | 左 | 0 | -1 | 列号减 1 |

例如牛在 `(5, 7)`，现在朝右，`dc = 1`：正前方是 `(5, 8)`。想换方向，只要把编号 +1 再对 4 取余（`(dc+1)%4`），就会按"上→右→下→左→上"转圈。

**重点 2：为什么农夫在代码里"后走"，也算同时行动？**

题目里的牛和农夫只会检查边界和障碍物 `*`，**不会把对方当成障碍物**。所以先计算牛、再计算农夫，结果和同时计算相同。两个人都走完以后，才把 `time` 加 1，并检查是否相遇。

**重点 3：为什么是 160000？**

一个角色的状态 = 位置（10×10 共 100 种）× 方向（4 种）= 400 种。两个人合在一起最多 `400 × 400 = 160000` 种组合状态。如果已经走了这么久还没碰面，下一次一定会回到以前出现过的"牛的位置、牛的方向、农夫的位置、农夫的方向"组合，之后就是重复走同样的路，永远不会相遇。

**两个方法对比**：

| | 方法 1 | 方法 2 |
| --- | --- | --- |
| 方向处理 | 4 个 if 判断 | `dx`/`dy` 方向数组查表 |
| 防死循环 | "农夫回起点且朝上"等组合特判 | 状态总数 160000 上限 |
| 代码长度 | 较长 | 更短、更好扩展 |

### 复杂度

最多模拟 160000 次，每次只做少量计算，所以时间是 `O(160000)`，很快；地图只占 10×10 格，空间是 `O(1)`。

## 4. P2615 神奇的幻方

![P2615 神奇的幻方示意图](assets/walkthrough/P2615.webp)

### 题目在做什么？

输入一个奇数 `n`，要填出一个 `n × n` 的幻方：把 1 到 `n²` 各填一次，并且每行、每列、两条对角线的和都相同。

题目已经给了一套填数字的规则。我们只要严格照做，就能成功。

### 填数规则换成简单的话

1. 数字 1 固定填在第一行正中间。
2. 假设刚把数字 `k` 填在 `(x, y)`：想把下一个数字填到“右上角” `(x-1, y+1)`。
3. 如果刚刚的数字在第一行，但不在最后一列，下一个数字要跑到最后一行、右边一列。
4. 如果刚刚的数字在最后一列，但不在第一行，下一个数字要跑到上面一行、第一列。
5. 如果刚刚在右上角，下一个数字要跑到它正下方。
6. 如果右上角的位置已经有数字了，下一个数字也填到它正下方。
7. 其余普通情况，就填右上角。

### 示例代码（逐行注释）

```cpp
#include <bits/stdc++.h>                 // 引入常用工具
using namespace std;                     // 使用标准命名空间

int main() {
    int n;                               // n 是幻方的边长，题目保证它是奇数
    cin >> n;                            // 读入 n

    vector<vector<int>> a(n, vector<int>(n, 0)); // 做 n 行 n 列的表格，开始全是 0

    int x = 0;                           // 1 的行号：第一行是 0
    int y = n / 2;                       // 1 的列号：正中间这一列
    a[x][y] = 1;                         // 把数字 1 放进去

    for (int num = 2; num <= n * n; num++) { // 从 2 一直填到 n²
        if (x == 0 && y != n - 1) {      // 情况 1：在第一行，但不是最后一列
            x = n - 1;                   // 行绕到最后一行
            y = y + 1;                   // 列向右一格
        } else if (y == n - 1 && x != 0) { // 情况 2：在最后一列，但不是第一行
            x = x - 1;                   // 行向上一格
            y = 0;                       // 列绕到第一列
        } else if (x == 0 && y == n - 1) { // 情况 3：恰好在右上角
            x = x + 1;                   // 直接到正下方一格
        } else if (a[x - 1][y + 1] != 0) { // 情况 4：右上角本来已经被填过
            x = x + 1;                   // 也填到当前数字的正下方
        } else {                         // 情况 5：普通情况，右上角是空的
            x = x - 1;                   // 行向上一格
            y = y + 1;                   // 列向右一格
        }

        a[x][y] = num;                   // 在刚刚算出的新位置填入 num
    }

    for (int i = 0; i < n; i++) {        // 一行一行输出
        for (int j = 0; j < n; j++) {    // 输出这一行的每一列
            cout << a[i][j];             // 输出当前格子里的数字
            if (j != n - 1) cout << ' '; // 最后一个数字后不多输出空格
        }
        cout << '\n';                    // 一行输出完，换行
    }

    return 0;                            // 程序正常结束
}
```

### 为什么 `a[x - 1][y + 1]` 不会越界？

看到这一行可能会担心：`x - 1` 或 `y + 1` 会不会跑出表格？不会，因为前面的三个 `if` 已经先把会越界的情况处理完了：

- `x == 0`（第一行）会在前两个有关第一行的分支处理；
- `y == n - 1`（最后一列）也会被前面的分支处理。

所以执行到“右上角是否已填”这一行时，一定有 `x > 0` 且 `y < n - 1`，坐标安全。

### 复杂度

要填 `n²` 个格子，再输出 `n²` 个格子，所以时间为 `O(n²)`；幻方表格占 `O(n²)` 空间。

## 最后的学习小结

这四题分别训练了四种很常见的基本能力：

| 题目 | 主要练习 |
| --- | --- |
| 玩具谜题 | 环形数组、取余数、位置移动 |

| 神奇的幻方 | 二维数组、把文字规则翻译成 `if / else if` |

做模拟题最可靠的方法是：**把题目的一条规则，翻译成代码中的一个小判断。** 不要跳步，也不要觉得规则“应该差不多”；严格照题意写，答案就会出现。
