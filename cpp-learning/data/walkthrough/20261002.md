# 26国庆01

适合小学六年级的 C++ 题解。建议按“读懂任务 → 手算例子 → 看代码 → 自己练习”的顺序学习。

四道题的代码都是独立程序。提交时，只复制当前题目的一份代码，不要把四个 `main` 放在一起。文中的练习输入输出是自拟的，用来帮助理解。

### 先认识几个常用符号

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `a / b` | 两个整数相除，只保留整数部分 | `123 / 10` 得到 `12` |
| `a % b` | 除法的余数 | `123 % 10` 得到 `3` |
| `==`、`!=` | 相等、不相等的判断 | `a == 0` 判断 a 是否为 0 |
| `&&`、`\|\|` | 并且、或者 | `&&` 要求两边都成立；`\|\|` 只需至少一边成立 |
| `i++`、`i--` | 加 1、减 1 | 等同于 `i = i + 1`、`i = i - 1` |
| `continue` | 跳过这轮循环的剩余代码 | 直接开始下一轮 |
| `bool` | 保存“是或否” | `true` 是成立，`false` 是不成立 |

代码中的 `//` 后面都是给人看的注释，电脑不会执行它们。

## 1. P1307 数字反转

![P1307 数字反转示意图](assets/walkthrough/P1307.webp)


题目来源：[洛谷 P1307](https://www.luogu.com.cn/problem/P1307)。以下用自己的话解释解法，详细输入输出要求以题目页面为准。

### 任务与思路

把整数的数字倒过来，负数保留负号。例如 `-120` 的答案是 `-21`。

可以想象从右往左拿积木，再从左往右搭起来：

1. 先记住正负号，把数字变成非负数。
2. 用 `% 10` 拿出最右边的数字。
3. 用“答案乘 10，再加这个数字”把它接到答案右边。
4. 用 `/ 10` 去掉已经拿走的数字。

以 `120` 为例：

| 当前 n | 拿出的数字 | 新答案 | 去掉末位后的 n |
| --- | --- | --- | --- |
| 120 | 0 | 0 × 10 + 0 = 0 | 12 |
| 12 | 2 | 0 × 10 + 2 = 2 | 1 |
| 1 | 1 | 2 × 10 + 1 = 21 | 0 |

整数不会保存开头的零，所以不需要额外删除零。输入是 `0` 时，循环不执行，答案仍然是 `0`。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 让我们可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int n; // 保存输入的整数。
    cin >> n; // 读入整数。
    int sign = 1; // 先假设答案是正数。
    if (n < 0) { // 如果原来的数是负数。
        sign = -1; // 记住负号。
        n = -n; // 把 n 变成正数，方便处理数字。
    } // 负号处理结束。
    int answer = 0; // 从 0 开始拼出反转后的数。
    while (n > 0) { // 只要还有数字没有取出，就继续。
        int digit = n % 10; // 取出最右边的一位数字。
        answer = answer * 10 + digit; // 把这位数字接到答案右边。
        n = n / 10; // 去掉已经取出的最右边一位。
    } // 所有数字处理完毕。
    cout << answer * sign << '\n'; // 把原来的正负号还原，并输出答案。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自己检查

| 输入 | 输出 | 检查什么 |
| --- | --- | --- |
| `123` | `321` | 普通正数 |
| `-120` | `-21` | 负号和末尾零 |
| `1000` | `1` | 多个末尾零 |
| `0` | `0` | 循环一次也不执行 |

每位数字只处理一次，最多处理 10 位；只需要几个整数变量。题目范围内，原数和反转后的数都能放进 `int`。

小练习：把输入换成 `-3050`，在纸上写出每轮的 `n`、`digit` 和 `answer`。

## 2. P1067 多项式输出

![P1067 多项式输出示意图](assets/walkthrough/P1067.webp)


题目来源：[洛谷 P1067](https://www.luogu.com.cn/problem/P1067)。以下用自己的话解释解法，详细输入输出要求以题目页面为准。

### 任务与思路

这道题不要求计算多项式的值，只要求把它写得规范。可以把一项拆成“符号、系数、字母、指数”四部分，分别决定要不要输出。

先认识名称：在 `3x^2` 中，`3` 是系数，`2` 是次数；常数项没有 `x`，次数为 `0`。

| 当前这一项 | 应该写成 | 原因 |
| --- | --- | --- |
| 系数 0，次数 3 | 不写 | 这一项不存在 |
| 系数 1，次数 3 | `x^3` | 有 x 时省略系数 1 |
| 系数 -1，次数 1 | `-x` | 保留负号，省略 1 和指数 |
| 系数 1，次数 0 | `1` | 常数项的 1 不能省略 |

用 `first` 记住“是不是第一项”。第一项为正时不用加号，后面的正数项需要加号。负数项始终需要负号。

不必用数组保存所有系数：读入一个系数，就把这一项处理完，再读下一个。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 让我们可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int n; // 保存多项式的最高次数。
    cin >> n; // 读入最高次数。
    bool first = true; // true 表示还没有输出过任何一项。
    for (int power = n; power >= 0; power--) { // 从最高次一直处理到常数项。
        int a; // 保存当前这一项的系数。
        cin >> a; // 读入当前系数。
        if (a == 0) { // 系数为 0 的项不需要输出。
            continue; // 跳过这一项，直接处理下一项。
        } // 是否跳过的判断结束。
        if (a < 0) { // 如果当前系数是负数。
            cout << '-'; // 输出负号，包括第一项的负号。
        } else if (!first) { // 如果是正数，而且前面已经输出过一项。
            cout << '+'; // 在两项之间输出加号。
        } // 符号处理结束。
        int value = a; // 准备计算系数的绝对值。
        if (value < 0) { // 如果系数为负。
            value = -value; // 去掉负号，得到绝对值。
        } // 绝对值处理结束。
        if (value != 1 || power == 0) { // 系数不是 1，或者这一项是常数项。
            cout << value; // 输出系数的绝对值。
        } // 系数处理结束。
        if (power >= 1) { // 一次项及以上才有 x。
            cout << 'x'; // 输出字母 x。
        } // 字母处理结束。
        if (power >= 2) { // 二次项及以上还要写出指数。
            cout << '^' << power; // 例如输出 ^3。
        } // 指数处理结束。
        first = false; // 记住：现在已经输出过一项了。
    } // 全部系数处理完毕。
    if (first) { // 如果所有项都被跳过，作为补充处理输出 0。
        cout << 0; // 零多项式写成 0。
    } // 补充处理结束。
    cout << '\n'; // 输出换行。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自己检查

输入：

```text
5
1 0 -1 2 0 -1
```

输出：

```text
x^5-x^3+2x^2-1
```

从左到右的六个系数，分别对应 5、4、3、2、1、0 次项。

再试试：

| 输入第一行 | 输入第二行 | 输出 |
| --- | --- | --- |
| `1` | `-1 1` | `-x+1` |
| `0` | `1` | `1` |
| `2` | `2 0 0` | `2x^2` |

容易错的地方：不要输出 `1x`，不要输出 `x^1`，不要省略常数项的 `1`，不要输出多余空格。

每个系数处理一次，共处理 n + 1 个系数；只需要几个变量。

小练习：输入次数 `3`，系数 `-1 2 0 1`，自己写出输出。

## 3. P2010 回文日期

![P2010 回文日期示意图](assets/walkthrough/P2010.webp)


题目来源：[洛谷 P2010](https://www.luogu.com.cn/problem/P2010)。以下用自己的话解释解法，详细输入输出要求以题目页面为准。

### 任务与思路

回文就是正着读、倒着读都一样，例如 `20100102`。

不用检查每一天。八位回文的前四位一旦确定，后四位就必须是它们的倒序！

```text
年份：a b c d
日期：a b c d d c b a
月份：d c
日：  b a
```

例如年份是 `2010`，就只能配成月份 `01`、日 `02`，得到 `20100102`。因此，每年最多只有一个候选日期。

逐年做三件事：拼出候选日期，检查月份和日是否真实存在，再检查它是否在给定区间内。回文只保证数字对称，不保证日期合法。

`days[month]` 就像查日历表：`days[1]` 是一月天数，`days[2]` 是二月天数。数组第一个位置的下标是 0，因此放一个不用的 0，让月份和下标对齐。

闰年口诀：能被 4 整除通常是闰年；整百年份还必须能被 400 整除。代码用“非整百的 4 的倍数，或者 400 的倍数”表达这个规则。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
using namespace std; // 让我们可以直接写 cin 和 cout。
int main() { // 程序从这里开始。
    int beginDate, endDate; // 保存起始日期和结束日期。
    cin >> beginDate >> endDate; // 读入两个日期，换行也可以分隔输入。
    int answer = 0; // 记录符合条件的日期个数。
    for (int year = beginDate / 10000; year <= endDate / 10000; year++) { // 逐年检查。
        int a = year / 1000; // 取出年份的千位。
        int b = year / 100 % 10; // 取出年份的百位。
        int c = year / 10 % 10; // 取出年份的十位。
        int d = year % 10; // 取出年份的个位。
        int month = d * 10 + c; // 回文要求月份是年份的个位、十位。
        int day = b * 10 + a; // 回文要求日期是年份的百位、千位。
        if (month < 1 || month > 12) { // 月份必须在 1 到 12 之间。
            continue; // 月份不合法，跳过这一年。
        } // 月份检查结束。
        int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; // 下标 1 到 12 存各月天数。
        bool leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0); // 按闰年规则判断。
        if (leap) { // 如果这一年是闰年。
            days[2] = 29; // 把二月天数改成 29。
        } // 闰年处理结束。
        if (day < 1 || day > days[month]) { // 日期必须在这个月的有效天数内。
            continue; // 日期不合法，跳过这一年。
        } // 日期检查结束。
        int date = year * 10000 + month * 100 + day; // 拼成八位的年月日数字。
        if (date >= beginDate && date <= endDate) { // 两个端点也算在范围内。
            answer++; // 找到一个符合条件的日期，数量加 1。
        } // 范围检查结束。
    } // 所有年份检查完毕。
    cout << answer << '\n'; // 输出回文日期的总数。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自己检查

输入：

```text
20100101
20101231
```

输出：

```text
1
```

这一年的候选日期是 `20100102`，日期合法，也在范围内。

| 起始日期 | 结束日期 | 输出 | 原因 |
| --- | --- | --- | --- |
| `20100102` | `20100102` | `1` | 两个端点都要算 |
| `20100103` | `20101231` | `0` | 候选日期早于起点 |
| `20200101` | `20201231` | `1` | 候选日期为 2020 年 2 月 2 日 |

容易错的地方：月份为 0 或大于 12 时，必须先跳过，不能拿这个月份去查数组；二月的天数要根据当前年份重新判断。

四位年份最多从 1000 到 9999，因此最多检查 9000 年。每年只做少量计算，额外只用几个变量和一个 13 个元素的数组。

小练习：年份 `2030` 拼出的月份和日各是多少？它是合法日期吗？

## 4. P1308 统计单词数

![P1308 统计单词数示意图](assets/walkthrough/P1308.webp)


题目来源：[洛谷 P1308](https://www.luogu.com.cn/problem/P1308)。以下用自己的话解释解法，详细输入输出要求以题目页面为准。

### 任务与思路

我们要找到完整单词，大小写不影响匹配，并记录次数和第一次出现的位置。

把文章想成一排格子，每个字母和空格各占一格，下标从 0 开始。

1. 用 `getline` 读入整行，保留空格。
2. 把目标单词和文章中的大写字母变成小写。
3. 遇到空格就向右走，遇到字母就收集一个完整单词。
4. 完整单词相同才计数，第一次找到时记下它的起点。

例如查找 `To`，文章是 `to today TO`：

| 完整单词 | 起点 | 是否计数 |
| --- | --- | --- |
| `to` | 0 | 是 |
| `today` | 3 | 否 |
| `TO` | 9 | 是，转成小写后相同 |

答案是 `2 0`。我们保留全部空格，所以开头有空格、单词之间有多个空格时，位置仍然正确。

`string` 可以理解为一串字符；`text[i]` 表示第 i 个位置的字符；`size()` 是字符数量；`current += text[i]` 表示在当前单词末尾添上一个字符。

字母转换可以理解为找编号：`'C' - 'A'` 得到 2，再用 `'a' + 2` 得到 `'c'`。只转换大写字母，其他字符保持原样。

### 逐行注释代码

```cpp
#include <iostream> // 使用输入和输出工具。
#include <string> // 使用 string 保存单词和文章。
using namespace std; // 让我们可以直接写 cin、cout 和 string。
int main() { // 程序从这里开始。
    string word, text; // word 保存目标单词，text 保存整篇文章。
    getline(cin, word); // 读入第一行的目标单词。
    getline(cin, text); // 读入第二行，保留文章中的所有空格。
    for (int i = 0; i < (int)word.size(); i++) { // 逐个检查目标单词的字母。
        if (word[i] >= 'A' && word[i] <= 'Z') { // 判断当前字母是否为大写字母。
            word[i] = word[i] - 'A' + 'a'; // 把大写字母换成对应的小写字母。
        } // 大小写判断结束。
    } // 目标单词转换完毕。
    for (int i = 0; i < (int)text.size(); i++) { // 逐个检查文章里的字符。
        if (text[i] >= 'A' && text[i] <= 'Z') { // 如果当前字符是大写字母。
            text[i] = text[i] - 'A' + 'a'; // 把它换成小写字母，空格保持原样。
        } // 大小写判断结束。
    } // 文章转换完毕。
    int count = 0; // 记录目标单词出现的次数。
    int first = -1; // 保存第一次出现的位置，-1 表示还没找到。
    int i = 0; // 从文章下标 0 开始扫描。
    int length = (int)text.size(); // 保存文章的字符总数。
    while (i < length) { // 只要还没有走到文章末尾，就继续。
        if (text[i] == ' ') { // 如果当前位置是空格。
            i++; // 向右走一个位置。
            continue; // 回到循环开头，继续寻找单词。
        } // 空格判断结束。
        int start = i; // 记住当前单词的起点。
        string current = ""; // 准备收集当前这个完整的单词。
        while (i < length && text[i] != ' ') { // 没到末尾、也没遇到空格时继续收集。
            current += text[i]; // 把当前字母接到单词后面。
            i++; // 向右走一个位置。
        } // 当前单词收集完毕。
        if (current == word) { // 比较两个完整单词是否相同。
            count++; // 找到一次，次数加 1。
            if (first == -1) { // 如果这是第一次找到。
                first = start; // 保存这个单词在原文章中的起点。
            } // 首次位置处理结束。
        } // 单词比较结束。
    } // 整篇文章扫描完毕。
    if (count == 0) { // 如果一次也没有找到。
        cout << -1 << '\n'; // 按题目要求输出 -1。
    } else { // 如果找到了目标单词。
        cout << count << ' ' << first << '\n'; // 输出次数和第一次出现的位置。
    } // 输出处理结束。
    return 0; // 程序正常结束。
} // main 函数结束。
```

### 自己检查

输入：

```text
To
to today TO
```

输出：

```text
2 0
```

再测试开头的空格：下面第二行开头有两个空格。

```text
To
  to today TO
```

输出是 `2 2`。如果查找 `to`，文章只有 `today`，输出应为 `-1`。

容易错的地方：`cin >> text` 读到空格就停，不能读取整篇文章；不能把 `today` 中的 `to` 算成一个单词；下标从 0 开始，空格也要占位置。

循环条件先检查 `i < length`，再访问 `text[i]`。`&&` 在左边不成立时不会继续判断右边，因此不会访问文章末尾以外的位置。

扫描位置 i 只向右走，文章长度为 L 时，工作量随 L 成正比。这种写法能处理题目中最长的一百万个字符。保存文章及当前单词需要随 L 增长的存储空间。

小练习：查找 `a`，文章为 ` A  a aa `，次数和第一次出现的位置是多少？
