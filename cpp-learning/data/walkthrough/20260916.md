# 五道模拟题：给六年级同学的逐行讲解（C++）

这五题的共同秘诀是：**题目怎样规定，我们就怎样一步一步做。** 这叫“模拟”。把每一句规则翻成一小段代码，就不会乱。

---

## 1. P5661 公交换乘

![P5661 公交换乘示意图](assets/walkthrough/P5661.webp)

### 题目在做什么？

坐地铁要付钱，但会得到一张优惠票。45 分钟内坐公交时，如果有一张还没过期、并且地铁票价不低于本次公交票价的优惠票，就必须用它，公交免费。

有好几张能用时，必须使用**最早得到**的那一张。问所有出行一共花多少钱。

### 思路：把优惠票放进“小队列”

每坐一次地铁：

1. 地铁票价加入总花费；
2. 记下一张优惠票的“票价、得到时间、是否已用”。

每坐一次公交：从最早的优惠票开始找，找到第一张同时满足下面三个条件的票就使用它：

- 没有用过；
- 还在 45 分钟有效期内；
- 优惠票的票价 `>=` 公交票价。

找到了公交免费；找不到就支付公交票价。

因为记录不会在同一分钟出现，所以 45 分钟内最多只有 45 条记录。每次公交最多检查约 45 张票，非常快。

### 代码（逐行注释）

```cpp
#include <bits/stdc++.h>             // 引入常用 C++ 工具
using namespace std;                 // 后面可直接写 vector、cin 等名字

struct Ticket {                      // 一张优惠票需要记住的三件事
    int price;                       // 它来自一趟多少钱的地铁
    int time;                        // 它是什么时间得到的
    bool used;                       // 它是否已经被公交用掉
};

int main() {
    int n;                           // n 是乘车记录数
    cin >> n;                        // 读入记录数

    vector<Ticket> tickets;          // 用一个列表保存所有曾得到的优惠票
    int first = 0;                   // first 前面的票已经过期，以后不用再看
    int answer = 0;                  // answer 是目前总花费，开始为 0

    for (int i = 0; i < n; i++) {    // 一条一条按时间顺序处理记录
        int type, price, time;       // type：0 地铁、1 公交；另有票价和时间
        cin >> type >> price >> time; // 读入这一条记录

        while (first < (int)tickets.size() && // 只要列表里还有票可检查
               time - tickets[first].time > 45) { // 且最早那张已经超过 45 分钟
            first++;                   // 跳过这张永久过期的票
        }

        if (type == 0) {             // 如果这次坐的是地铁
            answer += price;         // 地铁不能用优惠票，所以一定要付款
            tickets.push_back({price, time, false}); // 得到一张新的、还没用的优惠票
        } else {                     // 否则，这次坐的是公交
            bool freeRide = false;   // 先假设不能免费

            for (int j = first; j < (int)tickets.size(); j++) { // 从最早的未过期票开始检查
                bool notUsed = !tickets[j].used;             // 条件 1：还没使用过
                bool notExpired = time - tickets[j].time <= 45; // 条件 2：没有过期
                bool enoughMoney = tickets[j].price >= price;   // 条件 3：票价够用

                if (notUsed && notExpired && enoughMoney) { // 三个条件都满足
                    tickets[j].used = true;                  // 把这张票标记为已使用
                    freeRide = true;                          // 这次公交免费
                    break;                                    // 找到最早能用的票，停止寻找
                }
            }

            if (!freeRide) answer += price; // 没有合适优惠票，才支付公交车费
        }
    }

    cout << answer << '\n';          // 输出所有行程的总花费
    return 0;                         // 程序正常结束
}
```

### 容易错的地方

一张“票价太低”的优惠票，这次不能用，不代表它没有用了：以后可能来一趟更便宜的公交。因此不能因为它不合适就删掉它，只能在真正使用时标记 `used = true`。

### 复杂度

每条公交记录最多看约 45 张近时间得到的票，所以总时间约 `O(45n)`，也可看作 `O(n)`；存储空间是 `O(n)`。

## 2. P1190 接水问题

![P1190 接水问题示意图](assets/walkthrough/P1190.webp)

### 题目在做什么？

有 `m` 个水龙头和 `n` 位同学。前 `m` 位同学先各占一个水龙头。谁先接完，队伍里下一位同学马上接替他的水龙头。问所有人都接完需要多久。

### 思路：记录每个水龙头“忙到几点”

`finish[j]` 表示第 `j` 个水龙头已经安排到第几秒。

每来一位同学，他一定会接替**最早空出来**的水龙头。也就是在所有 `finish` 里找最小值。若该同学要接 `water` 秒，就把这个最小值加上 `water`。最后所有水龙头中最大的完成时间，就是所有人都接完的时刻。

### 代码（逐行注释）

```cpp
#include <bits/stdc++.h>                // 引入常用工具
using namespace std;                    // 使用标准命名空间

int main() {
    int n, m;                           // n 是同学数，m 是水龙头数
    cin >> n >> m;                      // 读入 n 和 m

    vector<int> finish(m, 0);           // 每个水龙头当前忙到的时间；一开始都为 0

    for (int i = 0; i < n; i++) {       // 按排队顺序处理每一位同学
        int water;                      // water 是该同学需要接多少秒水
        cin >> water;                   // 读入他的接水量

        int best = 0;                   // 先假定第 0 个水龙头最早空出来
        for (int j = 1; j < m; j++) {   // 比较其余水龙头
            if (finish[j] < finish[best]) { // 如果第 j 个更早空出来
                best = j;               // 就记住第 j 个水龙头
            }
        }

        finish[best] += water;          // 这位同学从它空出的时刻开始接水
    }

    int answer = 0;                     // 用 answer 寻找最晚完成的时刻
    for (int j = 0; j < m; j++) {       // 查看每个水龙头
        answer = max(answer, finish[j]); // 保留较大的完成时间
    }

    cout << answer << '\n';            // 输出所有人都接完水的时间
    return 0;                           // 程序正常结束
}
```

### 小例子

有 3 个水龙头，前三位同学分别需要 `4、4、1` 秒，水龙头的完成时间会变成 `[4, 4, 1]`。下一位同学一定接替第三个水龙头，因为它第 1 秒就空出来了。

### 复杂度

每位同学都比较 `m` 个水龙头，所以时间是 `O(nm)`。题目中 `m ≤ 100`，完全来得及；空间 `O(m)`。

## 3. P1042 乒乓球

![P1042 乒乓球示意图](assets/walkthrough/P1042.webp)

### 题目在做什么？

输入是一串每个球的结果：`W` 表示华华得一分，`L` 表示对手得一分，`E` 表示记录结束。要分别按 11 分制和 21 分制计算每局比分。

一局结束要同时满足：

- 有一方达到目标分数（11 或 21）；
- 两人分数相差至少 2 分。

所以 `11:10` 还不能结束，必须打到 `12:10` 或 `10:12` 才行。

### 思路：写一个“记分员”函数

11 分制和 21 分制做的事完全一样，只有目标分数不同。因此写 `printScore(record, limit)`：

- 一个字符一个字符看；
- 遇到 `W`，华华分数加 1；遇到 `L`，对手加 1；
- 一局满足结束条件就输出，并把双方分数清零；
- 所有记录看完后，还要输出正在进行的最后一局（哪怕是 `0:0`）。

### 代码（逐行注释）

```cpp
#include <bits/stdc++.h>                    // 引入常用工具
using namespace std;                        // 使用标准命名空间

void printScore(const string &record, int limit) { // 按 limit 分制输出每局比分
    int w = 0;                              // w 是华华在当前局的得分
    int l = 0;                              // l 是对手在当前局的得分

    for (char ch : record) {                // 依次查看记录中的每一个字母
        if (ch == 'W') w++;                 // W：华华得一分
        else if (ch == 'L') l++;            // L：对手得一分

        bool enoughScore = max(w, l) >= limit; // 是否已有一方达到目标分数？
        bool enoughGap = abs(w - l) >= 2;      // 两人的分差是否至少为 2？

        if (enoughScore && enoughGap) {     // 两个条件都满足，当前局结束
            cout << w << ':' << l << '\n'; // 输出这一局的最终比分
            w = 0;                          // 新的一局立刻开始，华华分数归零
            l = 0;                          // 对手分数也归零
        }
    }

    cout << w << ':' << l << '\n';         // 输出最后尚未结束的那一局
}

int main() {
    string record;                          // 用字符串保存 E 前的所有 W 和 L
    char ch;                                // 每次读入一个字符

    while (cin >> ch && ch != 'E') {        // 一直读，读到 E 就停止
        if (ch == 'W' || ch == 'L') {       // 只保存真正的得分记录
            record += ch;                   // 把这个字母接在字符串末尾
        }
    }

    printScore(record, 11);                 // 先按 11 分制输出
    cout << '\n';                          // 两种赛制之间需要一个空行
    printScore(record, 21);                 // 再按 21 分制输出

    return 0;                               // 程序正常结束
}
```

### 复杂度

记录会被 11 分制和 21 分制各读一遍，因此时间 `O(k)`（`k` 是字符数量）；空间 `O(k)`。

## 4. P1328 生活大爆炸版石头剪刀布

![P1328 石头剪刀布示意图](assets/walkthrough/P1328.webp)

### 题目在做什么？

两位同学循环出拳，手势用 `0~4` 表示。A 的周期长度是 `na`，B 的周期长度是 `nb`，总共玩 `n` 局。要计算两人的总分。

题目中，5 种手势的规则可记为：

- 0 胜 1、2；
- 1 胜 2、3；
- 2 胜 3、4；
- 3 胜 4、0；
- 4 胜 0、1。

### 思路：胜负表 + 取余数循环

做一张 `win[5][5]` 表：`win[a][b]` 为 1，就表示 A 出 `a`、B 出 `b` 时，A 获胜。

第 `i` 局时：

- A 出 `a[i % na]`；
- B 出 `b[i % nb]`。

`%` 叫取余数，能让下标到周期末尾后回到开头。例如 A 的周期是 3，局数下标依次是 `0, 1, 2, 0, 1, 2...`。

### 代码（逐行注释）

```cpp
#include <bits/stdc++.h>                 // 引入常用工具
using namespace std;                     // 使用标准命名空间

int main() {
    int n, na, nb;                       // n 总局数，na 和 nb 是两人的周期长度
    cin >> n >> na >> nb;                // 读入三个数

    vector<int> a(na), b(nb);            // a、b 分别保存 A 和 B 的出拳周期
    for (int i = 0; i < na; i++) cin >> a[i]; // 读入 A 的全部周期手势
    for (int i = 0; i < nb; i++) cin >> b[i]; // 读入 B 的全部周期手势

    int win[5][5] = {                    // win[x][y] 为 1：x 打败 y
        {0, 1, 1, 0, 0},                 // 0 胜 1、2
        {0, 0, 1, 1, 0},                 // 1 胜 2、3
        {0, 0, 0, 1, 1},                 // 2 胜 3、4
        {1, 0, 0, 0, 1},                 // 3 胜 0、4
        {1, 1, 0, 0, 0}                  // 4 胜 0、1
    };

    int scoreA = 0, scoreB = 0;          // 两人的分数都从 0 开始

    for (int i = 0; i < n; i++) {        // 依次模拟 n 局
        int handA = a[i % na];           // A 本局的手势；% 让周期自动循环
        int handB = b[i % nb];           // B 本局的手势

        if (win[handA][handB] == 1) {    // 若 A 的手势能打败 B 的手势
            scoreA++;                    // A 得 1 分
        } else if (win[handB][handA] == 1) { // 否则若 B 能打败 A
            scoreB++;                    // B 得 1 分
        }                                // 两个都不是 1 时，说明平局，谁也不得分
    }

    cout << scoreA << ' ' << scoreB << '\n'; // 按题目要求输出 A 分数和 B 分数
    return 0;                            // 程序正常结束
}
```

### 复杂度

每局只查一次表，时间 `O(n)`；两个周期的存储空间为 `O(na + nb)`。

## 5. P1003 铺地毯

![P1003 铺地毯示意图](assets/walkthrough/P1003.webp)

### 题目在做什么？

平面上按编号顺序铺了很多矩形地毯。后铺的地毯会盖住先铺的地毯。现在给一个点 `(x, y)`，问盖住它的最上面一张地毯编号；若没有地毯盖住它，输出 `-1`。

### 思路：倒着找

编号越大，铺得越晚，也就越在上面。因此从第 `n` 张地毯开始倒着检查：第一张能盖住目标点的，就是答案。

一张地毯左下角是 `(a, b)`，横向长度 `g`，纵向长度 `k`。它覆盖的范围是：

```text
a <= x <= a + g，并且 b <= y <= b + k
```

注意等号不能漏掉！题目说边界和顶点也算被覆盖。

### 代码（逐行注释）

```cpp
#include <bits/stdc++.h>               // 引入常用工具
using namespace std;                   // 使用标准命名空间

struct Carpet {                        // 一张地毯的四项信息
    int a, b;                           // 左下角坐标 (a,b)
    int g, k;                           // 横向长度 g，纵向长度 k
};

int main() {
    int n;                             // n 是地毯的数量
    cin >> n;                          // 读入 n

    vector<Carpet> carpets(n);         // 准备存放 n 张地毯
    for (int i = 0; i < n; i++) {      // 依次读入每张地毯
        cin >> carpets[i].a >> carpets[i].b // 读入左下角的横、纵坐标
            >> carpets[i].g >> carpets[i].k; // 再读入横向、纵向长度
    }

    int x, y;                          // 目标点的坐标
    cin >> x >> y;                     // 读入目标点

    for (int i = n - 1; i >= 0; i--) { // 从最后铺的地毯开始倒着检查
        int left = carpets[i].a;       // 地毯最左边的 x 坐标
        int right = carpets[i].a + carpets[i].g; // 地毯最右边的 x 坐标
        int bottom = carpets[i].b;     // 地毯最下边的 y 坐标
        int top = carpets[i].b + carpets[i].k;   // 地毯最上边的 y 坐标

        bool insideX = left <= x && x <= right;  // 目标点是否在横向范围内？
        bool insideY = bottom <= y && y <= top;  // 目标点是否在纵向范围内？

        if (insideX && insideY) {      // 横向、纵向都在范围内，说明被这张地毯盖住
            cout << i + 1 << '\n';     // 数组从 0 编号，题目从 1 编号，所以加 1
            return 0;                  // 倒着找到的第一张一定最上面，直接结束
        }
    }

    cout << -1 << '\n';               // 所有地毯都不覆盖这个点
    return 0;                          // 程序正常结束
}
```

### 复杂度

最多检查 `n` 张地毯，时间 `O(n)`；存储所有地毯需要 `O(n)` 空间。

## 最后的小结

| 题目 | 要练习的本领 |
| --- | --- |
| 公交换乘 | 按时间模拟、保存“是否用过”的状态 |
| 接水问题 | 找最早空闲的位置 |
| 乒乓球 | 字符串处理、计分规则、函数复用 |
| 升级石头剪刀布 | 胜负表、取余数实现循环 |
| 铺地毯 | 矩形范围判断、倒序查找 |

写模拟题时，请养成这个好习惯：先在纸上列出“需要记住什么”，例如位置、时间、分数、是否使用过；再把每条规则写成一个 `if`。这样题目再长也不怕。
