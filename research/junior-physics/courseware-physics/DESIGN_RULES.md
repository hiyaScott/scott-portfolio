# 物理课程ware设计规则

## 标题结构规则（重要）

### 大标题（h1）必须是章节主题名

**正确示例：**
```html
<h1>第七章 浮力</h1>
<div class="subtitle">BUOYANCY · 流体动力学实验室 · 第 7 / 18 章</div>
```

**错误示例：**
```html
<!-- ❌ 不要把主题代号/实验室名放在 h1 -->
<h1>📐 物理特工局</h1>
<div class="subtitle">沪科版八年级第一学期 · 第一章 · 学习手册</div>
```

### 规则总结

| 元素 | 内容 | 示例 |
|------|------|------|
| `<title>` | 第X章 主题 · CODE · 实验室 | `第七章 浮力 · BUOYANCY · 流体动力学实验室` |
| `<h1>` | **章节主题名**（核心） | `第七章 浮力` |
| `.subtitle` | CODE · 实验室 · 第 X / 18 章 | `BUOYANCY · 流体动力学实验室 · 第 7 / 18 章` |

## 其他规范

### TEMPLATE.html v1.0.0 结构
- 5 个标准单元
- 每单元 3 例题 + 3 测验题
- 进度条 5 段
- section 结构（showUnit 导航）
- quiz-btn + checkQuiz 标准交互

### 主题色
- 每章独立主题色（--accent）
- ch07: 紫色 #9d00ff
- ch08: 金色 #ffd166
- ch09: 橙色 #ff6b35

### div 必须平衡
- 提交前检查 `<div>` 开闭标签数量
